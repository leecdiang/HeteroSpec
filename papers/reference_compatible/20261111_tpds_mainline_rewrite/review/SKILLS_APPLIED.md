# Research and writing skills applied to this reconstruction

This review uses eight scientific research/writing skills plus two prose skills.
The skills organize the work; experimental claims come from the HeteroSpec
repository and cited primary publications.

The eight scientific skills were read at the fixed
[K-Dense-AI/scientific-agent-skills commit](https://github.com/K-Dense-AI/scientific-agent-skills/tree/2d2065fb4520fa3f3f2bcf61cff26ec8b7eba4b5).
Their application began with the approved narrative design and carries through
this completed manuscript.

| Skill | Version | Applied decision in the delivered paper |
|---|---:|---|
| scientific-writing | 2.3 | One question, two technical contributions, and the order problem → native diagnosis → construction → qualification → attribution → application cost. |
| scientific-critical-thinking | 1.5 | Distinguish endpoint agreement from full-vector/state agreement; preserve the scope of each causal intervention. |
| peer-review | 2.4 | Compare local cuts with maximal whole-graph rechunking and packing with a backend loop; separate graph-loop service evidence from stronger operator evidence. |
| hypothesis-generation | 2.4 | Present cropped/padded native replay and arithmetic controls as discriminating interventions, with the variables that were actually held fixed. |
| scientific-brainstorming | 1.4 | Choose reference-compatible parallel execution as the paper identity; keep state management and complete costs in service of that question. |
| literature-review | 1.11 | Organize related work by reference target, numerical organization and state, and verify all 16 bibliography entries against primary identities. |
| statistical-analysis | 2.0 | Retain paired-root dependence, multiplicity families, all fixed controls and the distinction between inherited and reconstructible intervals. |
| scientific-visualization | 1.4 | Build six argument-carrying main figures and three supplements with vector output, embedded fonts, complete observations and redundant color encodings. |
