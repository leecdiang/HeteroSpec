\section{Conclusion}
Fixed numerical references leave useful parallel work available in quantized LLM inference. Separating physical KV ranges from arithmetic groups allows the required attention boundaries to remain local while compatible projections and surrounding computation remain grouped. Output ownership and state commit rules make that execution usable by downstream consumers. The evaluated implementations provide a small but measurable service increment beyond a strong same-contract control, while component and application experiments explain why local cuts, wider verification and complete speculation have different outcomes. The method offers a compatibility-preserving execution option whose value can be assessed against both its own costs and the alternative of adopting a new numerical backend.
