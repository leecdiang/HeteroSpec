\section{Conclusion}
\label{sec:conclusion}
The useful speculative path is not necessarily the one suggested by favorable component measurements. In the tested stacks, output qualification can remove cheap verification, and the state interface can consume an isolated draft-device advantage. Two prospectively frozen direct-ID replications show that serialization reaches qualification on RTX but only improves agreement on B570. Serialization itself is not a certificate, and these qualification studies do not upgrade historical performance evidence. The runtime studies expose the resulting decisions: the 358H intervention stops at qualification, while M4 permits a prospective test of continued speculation using complete realized cost. That guard preserves exact outputs and remains profitable against target-only, without demonstrating an improvement over fixed speculation. The systems lesson is to distinguish physical opportunity, satisfaction of the intended output contract, and complete execution cost when evaluating a speculative runtime choice.
