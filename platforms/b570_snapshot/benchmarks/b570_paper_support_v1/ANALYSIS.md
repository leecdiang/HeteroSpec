# Analysis and paper evidence rules

The three possible useful outcomes are: (A) qualified transfer with lower PQ-relative cost, (B) qualified transfer with parity or higher cost, (C) a bounded transfer failure. None guarantees favorable performance. An engineering failure is a fourth, non-scientific outcome and must not be sold as a numerical counterexample.

Primary: C_R_PQ/C_R_QH. For each task/session/arm, take the median of the two measured request durations. Compute log ratios, then equal-task/equal-session geometric means. Report every task/session value, domain/length stratum, all three session estimates, regression identities, and the aggregate. Secondary ratios: M_R/C_R_QH and R/C_R_QH. Report complete-panel summed request times as a different statistic. Loading, warmup, monitoring, capture and delivery costs are additional accounting, not subtractable timing discounts.

Before cost claims, require complete expected measured AND warmup records, original-R endpoint stability across all requests/sessions, exact reference matching for BOTH arms of a contrast, valid timing/control/placement audits, and complete provenance. C_R_MQ pilot failure is allowed; S3 has no MQ arm. No successful-task filtering, replacement, imputation, synthetic endpoint, or earlier-run data fills gaps. Record full token IDs/EOG/terminal/stop/length, not only decoded text. An honest independent raw auditor produces the normalized `qualified` and endpoint hashes consumed by study.py.

Predeclared descriptive decision: primary overall ratio >1.02 AND every session ratio >1.00 => MEASURED_FIXED_PANEL_GAIN. Ratios exactly at threshold do not pass. This is not statistical significance or a population lower bound. All tasks/strata and regressions remain. If qualified but this rule fails, label QUALIFIED_TRANSFER_NO_PREDECLARED_GAIN; report the actual ratio even when slower. No CI from request bootstrap; three sessions are insufficient for confident date-population inference. External-device or universal claims are unsupported.

S1 result: native q2 correspondence on eight captured contexts, plus eight derived q1 controls; report those denominators separately. Four sentinels, layers and repeats are not independent prompts. Bitwise PQ/QH equality does not establish native kernel identity or reduction order. A finite mismatch is real even if endpoints later might agree; this protocol conservatively stops at that gate.

PAPER_EVIDENCE.md should have rows for logical mapping, backend acceptance, actual placement, finite numerical correspondence, whole-request reference preservation, PQ-relative cost, draft value, copy/packing overhead and remaining scope. Each row links a fixed raw/analysis source and states achieved/not achieved. Original QB4 remains unsupported under the frozen implementation; supported QH_C is an adapted representation, not identical QB. The paper's B570 addition is at most a compact adaptation result/table plus explicit limits, not a new main contribution. Do not edit the manuscript automatically.

The analyzer in this PR is a report-level aid. It checks normalized panel completeness, duplicate/missing records, repeated endpoint consistency and arithmetic. It cannot authenticate a claimed raw audit, prove real placement, check causal state provenance, verify first-use capture selection or measure resources. These obligations belong to the host's independent raw reconstruction and F0 gates.
