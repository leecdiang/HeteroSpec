## 对齐解释与实际观测

七个已计账宿主内实测 `minStorageBufferOffsetAlignment=64`。所有记录的独立根
起点均满足64字节对齐；视图的实际 buffer-relative offset 等于根偏移加展平 view offset，
所有张量范围均在其报告的 buffer 大小之内。这里是 buffer 内偏移，不是 DRAM 物理地址。

| 观测对象 | 实际起点 | descriptor起点 | delta | 观测结果 |
|---|---:|---:|---:|---|
| slot0 Q+32 |32|0|32| stderr为8301断言；进程退出3221226505 |
| slot1 Q0 |0|0|0| 公共q1完整返回，1024个最终值全部有限 |
| slot2 PQ第二列mask，根内252 |72956|72896|60| stderr为2595的src1零偏移断言；退出3221226505 |
| slot3 实际绑定的PQ slab j0/j1 |113536 /113792|同左|0 /0| 两条PQ链与完整图返回 |
| slot5 实际绑定的PQ slab j0/j1 |361856 /362944|同左|0 /0| K257完整图返回 |
| slot5 旧的未绑定mask view，根内1028 |272388|272384|4| 地址仍保留；该旧view未被softmax使用，没有对该绑定另跑负例 |

slot0 和slot2均重新调用**原冻结分类器**复核，身份、wire/raw哈希、实际偏移、指定
断言、退出状态、GRAPH_START与缺失GRAPH_RETURN全部满足后才被接受。其余错误未改名
为预期失败。七次 graph start、五次成功 return/output、两次断言的计账彼此分开。

这些观测有力支持：原Q+32不满足通用matvec起点要求；Q0消除这项夹具条件；PQ逐列
mask需要单独处理描述符起点，单独改变Q还不够。旧未绑定view即使不对齐也不影响新
绑定图成功，不能把“存在任意未对齐view”本身当失败判据。

没有动态调用栈，因此仍不声称唯一触发 tensor/调用行已动态确认。原S1也没有被
事后补写这些参数。slot0/2没有返回图、after-readback或数值文件，保持缺失；不补零，
也不从缺失推断全部shader均未执行。slot0失败，所以两个q1布局都返回时的逐位比较
条件不适用；slot1成功后才按计划进入q2。
