# RTX natural prefix replay execution

This is the independent native result branch from PR172 head `801196166c8e2a02215003301d129e68504e6b72`. The immutable scientific ancestor is PR171 `371223b696bb805030c29f04e39eb17b57fb2ebb`. Historical archives and original R are not overwritten.

The final service worker is `worker_service.cpp`, built as `candidate07`. It links the unchanged PR171 packed arithmetic core and original numerical DLL cohort. QB, WB-cut, WB-rechunk and AUTO share those arithmetic assets. The scalar executable links the original PR166/168 core. Build bindings retain exact commands, source bytes, executable/core/module hashes and failed or superseded epochs.

The deployment is Qwen3-8B Q8_0, C4096, F16 KV, non-flash, target-only, all GPU, q32 and ordinary greedy cap128/native EOG. A model and one context remain resident within a timed session. The cache is an immutable, exact-token, file-backed sequence snapshot. Every request reads that snapshot, builds the prefix index, resets the context, looks up/imports state, selects one append route, appends, generates, synchronizes and commits an owned response. These operations are inside the final native service clock. Model/context creation and benchmark evidence serialization are outside and separately retained in process receipts. This is not zero-copy cache binding or a production engine throughput claim.

The pinned OASST1 source is `OpenAssistant/oasst1` revision `56e16363c12104182b8ad8173591b4d1e31c1faa`, file `2023-04-12_oasst_all.messages.jsonl.gz`, SHA256 `2ff4aa8999c911ffec7972ddf70359f220b3da184b731f3649f68b1391e19341`. Both complete histories use the native GGUF-selected renderer and tokenizer. The shared cohort uses actual user leaves, not intermediate user nodes. Its 44 IDs and cached/request token hashes were independently matched against B570. The earlier broader RTX pool, original references, exposure audit and costs remain as engineering evidence. None of its exposed calibration roots entered the common test panel.

The output-free physical census calls the actual native allocator's `find_slot` and `apply_ubatch`, without computing KV bytes. Actual restored heads, positions, output ownership, complete continuation vectors and final sequence states are checked separately during native qualification. Extra all-known-append-vector probes have separate diagnostic binaries/output flags and are not substituted for service qualification.

All admitted requests append at least one known token. They therefore do not consume pre-snapshot logits; the first service decision uses the newly produced final prompt vector. Greedy sampling has no RNG or adaptive sampler state. The restored necessary state is the immutable sequence KV and its positions, followed by explicit dense-head checks, ordered caller-plan checks, pending-token ownership, full-vector/end-point checks and final position/state comparison. The independent continuous-scalar control checks the snapshot path against an unbroken prefix. These finite controls do not claim correctness for fragmented, multi-sequence or no-append cache hits.

## Original-host reproduction

Use Python3.11 and the exact assets identified in `evidence/HOST_ADMISSION.json`; change `host.ROOT` to a fresh directory. Never rerun an existing attempt or mutate historical paths. `host.py` retains original compiler/link commands; `evidence/native-source-kit.zip` contains both complete native source trees and the inherited adapter header/source entry. Extract the source kit to fresh paths and rebase the recorded include/library paths. CUDA DLLs must match the binding, not merely have the same filenames. The source kit is independently checksum-verified; that check is not third-party native replication.

The actual execution sequence is recorded in scripts and immutable launch manifests:

1. `corpus.py`, `prepare.py`: native initial corpus and pre-output audit; retained superseded interpretation.
2. `common_panel.py`, `native_census.py`, `common_manifest.py`: independently ranked common leaf panel and native allocator metadata.
3. `common_calibration.py references qualify cost`: immutable reference reuse or new original pairs, complete fixed-arm qualification, two calibration sessions and immediate warmups.
4. `diagnostic.py execute`: continuous scalar versus restored scalar and own-producer candidate roundtrips, with separately requested known-append vectors.
5. `common_fit.py`: deterministic registered selector and complete calibration campaign cost window.
6. After both real immutable peer freeze receipts are verified, `formal.py refs qualify cost aligned` executes the common held-out and aligned-control schedules. It refuses to launch without `COMMON_BLIND_GATE.json` and authenticated referenced bytes. Do not create a gate merely to bypass missing peer receipts.
7. `analyze.py`: read-only complete-slot and source-bound reconstruction, root-cluster bootstrap and full accounting. It refuses incomplete or unqualified panels.

The initial reservation is2048 requests. Interrupted process batches retain their entire reserved allocation conservatively, even when only some slots completed. No timing is extended in response to its sign. Source/accounting corrections are pre-freeze engineering epochs, and the earlier observations are never erased. In particular, an early service window omitted snapshot file I/O; its interrupted timing is not an admissible performance result.

## Evidence and limits

Raw archives use content-addressed blobs: identical vector/state files are stored once and every original path remains in the index. `archive.py` verifies delivered bytes and reconstructs equality from those bytes. Restored-download verification is recorded independently from source-host checks. The main analysis treats roots, not repeated requests, as sampling units; no GPU-population or cross-platform pooled estimate is computed. Four same-day sessions do not establish cross-date stability.

This README does not certify stages that have not run. Native receipts, the final status report and the complete slot ledger determine what was actually completed. A numerical failure withholds a whole-panel performance claim; an absent natural opportunity, constant selector or negative result remains a valid conclusion.

For a fresh supported Windows RTX host, `reproduce.py --runtime frozen-runtime.zip --raw raw-evidence.zip --model <pinned-GGUF> --slot main-cost-s0 --out <new-directory>` verifies the delivered binary/modules/model, materializes only the referenced immutable snapshots, rebases their paths and runs the original native manifest. Add `--prepare-only` for a non-forward preparation check. The runtime kit also includes static libraries and compiler/link bindings; Zig is the original `ziglang0.16.0` Windows package. Rebuilding or running on another backend/cohort requires new qualification, rather than assuming numerical equivalence from successful compilation.
