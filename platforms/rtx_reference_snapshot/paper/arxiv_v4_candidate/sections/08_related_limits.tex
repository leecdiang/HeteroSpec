\section{Related work and scope}
\label{sec:related}
\subsection{Numerical consistency}
Batch-invariant inference stabilizes normalization, matrix multiplication and attention, including split boundaries~\cite{thinkingmachines}. LayerCast separates storage precision from computation precision~\cite{layercast}, and TBIK aligns reductions across tensor-parallel configurations~\cite{tbik}. QB instead changes query/mask views within a fixed quantized, non-flash graph. It retains the existing arithmetic operators and measures correspondence to a specified ordinary reference.

CoRun uses isolated prefill and fixed-shape decode~\cite{corun}. LLM-42 adds fixed-shape verification and rollback around a fast path~\cite{llm42}; MarginGate selectively invokes verification using decision margins~\cite{margingate}. QB changes the target attention representation without adding a numerical-consistency verifier. The measured comparators are PQ and GS within the same runtime; external systems provide design context rather than measured speed comparisons.

Vosti specifies and verifies engine/kernel behavior across batching, chunking and cache changes~\cite{vosti}. That guarantee under stated assumptions has a different scope from our finite qualification against an existing deployment. Our evidence combines a logical mapping proof, runtime guards, operator replay and finite-panel endpoint qualification.

\subsection{State and performance}
Stage-Replay demonstrates suffix sensitivity to KV transplantation~\cite{stagereplay}; cache-dependent divergence in quantized serving is also reported~\cite{cachestate}. Our state experiments add fixed-precision partition interventions, component-substitution counterexamples and common-prefix scores. Activation-patching work has already established that metrics and intervention choices affect interpretation, including nonadditive component effects~\cite{patching,mediators}. Here the four-cell score contrast distinguishes an observed nonadditive response from an endpoint pattern that a threshold alone could produce.

Ragged-batch synchronization errors are a separate source of speculative-decoding failures~\cite{forensics}. A wrong position or mask map is a semantic error, whereas a correct map can still alter finite-precision evaluation or fail backend admission. The independent checks in this paper address those cases separately. Performance work also emphasizes verification cost and actual execution behavior~\cite{illusion,lossless}. Our cost contribution is the qualified PQ/QB comparison and its separation from global repair and draft profitability.

\subsection{Scope of the evidence}
The CUDA evaluation covers one logical sequence, non-flash attention, occupied $q\leq4$, Q8\_0 weights, F16 KV and supported Qwen3/dense Llama-family paths. The three pairs share backend components. E2 repeats an exposed panel on one host; E1 uses one prompt per family with short visible contexts despite physical key extent 256. Larger contexts, concurrency, other precisions and fused attention require separate qualification. The measured 3--6\% resident-request gains compare PQ/QB, not an optimized fused-attention serving stack; a stronger baseline must meet the same output contract.

Vulkan state interventions use four exposed inputs and finite greedy continuations. The stopped Llama Q6\_K port remains unqualified; the successful Qwen3 Q8\_0 port has a separate reference and runtime. Counterexamples, failed comparisons and missing vectors are retained with their affected results. Production throughput, energy, physical critical-path shares and hardware efficiency remain outside the measurements.

Each service panel uses four exposed inputs, one pair and one device/date. Recorded warmups establish neither cold-driver behavior nor cache residency for every shape; exclusive machine use is unverified. The RTX layout estimate is noise-limited, and neither panel establishes equivalence. The draft-prefill submission follow-up has qualification but incomplete timing. Clean timing and full-logit qualification are separate; manuscript checks reconstruct reported values, while runtime binaries and complete raw tensors remain separately held.
