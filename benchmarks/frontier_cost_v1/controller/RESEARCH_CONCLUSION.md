# Research judgment

**This release supports a testable method component, not a new complete decoder or a demonstrated 5% improvement.** The useful question is whether reference-compatible physical frontiers leave a residual execution opportunity that a strong cost-aware adaptive baseline cannot already exploit.

The implementation closes a concrete credibility gap: a raw-comparison PASS previously did not bind the complete run, inputs, deployment or repetition coverage. The new reader rejects the demonstrated altered receipts. That repair is necessary for optimization decisions; it is not itself a performance mechanism or a novelty claim.

The causal model now treats verification, stopping and reconciliation as separate charged actions. It distinguishes a token being revealed from its KV being materialized. It charges the controller at each reached decision and leaves already generated draft work sunk. These details make the hypothesis falsifiable. The present finite recursion still assumes all routes to a logical frontier share one sufficient cost-relevant state; actual graph/cache/path dependence would require a richer state key or disqualify the lookup. No physical-state convergence certificate has been implemented.

An independent gain near 5% would require the sum of **qualified, causally realizable savings across aligned request episodes** to exceed 5% of the complete strong-baseline request cost after all reconciliation and control work. The target-operation macro table cannot identify that sum, and different episodes or measurement blocks cannot be mixed to manufacture it. If a proposed stop changes later request boundaries, a real sequential experiment is required.

Two present observations argue for restraint. First, the public AR-draft trace already makes ordinary two-stage long-draft reveal a weak comparison against short k3/lazy drafting; beating fixed q8 alone would not establish the research goal. Second, in a newly executed past-only forecast diagnostic, the conditional-position Beta predictor was worse than the simpler direct first-four-frequency predictor (Brier 0.25757 versus 0.25185). This ordering is conditional on the declared initialization and exposed file order, without a significance or predictor-family claim. There is no predictor victory to convert into a performance story. The Python recursion also has measurable host overhead, which must be remeasured with a complete deployment adapter before it can enter any decision cost.

The architecture hypothesis remains conditional: an admitted short-circuit frontier may avoid enough useless suffix work to offset repeated weight traffic, synchronization, graph/cache disruption and required target/draft materialization. A positive result must identify such a real frontier, show that a simple calibrated adaptive baseline does not achieve the same result, and explain where the effect transfers. Generic adaptive length, Bayesian histories, Bellman recursion, profiled token-cost objectives and preverification have direct prior art. The possible contribution lies in the actual legal transformation and its independently measured residual effect.

The next experiment should therefore be small: select an existing reference-compatible action family on one actual deployment, add one independently qualified stage/terminal-convergence path, measure its complete resident cost, and compare it with the best equally optimized full-block, short-lazy and ordinary adaptive alternatives. Use development-only costs and forecasts, then test frozen choices on new sequential requests. If state qualification fails, extra control/reconciliation consumes the opportunity, or an ordinary adaptive baseline matches the result, keep the negative evidence and stop the new-method claim. The CPU q2 counterexample is evidence about that specific fixture/path; it is not a veto on every possible stage or on the original CUDA deployment.
