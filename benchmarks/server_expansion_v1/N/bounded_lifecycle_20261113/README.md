## Preserved failure and limits

The first strong attempt selected `hsc::begin("counts",0)`. The original backend installs evaluation callbacks only when `hsc::is_heavy()` is true, so recorded GPU/loop4 observations were0 and the independent gate correctly stopped LOCAL. This is an implementation/recording error, not numerical failure. One bounded successor changes observation mode to `heavy`, verifies the original failed parent fingerprint and carries18/4,470/5 cumulative charges before new work. All raw files and failure records remain. References, arithmetic, fixtures and strict comparison are unchanged. The retry confirms actual graph/placement observations and numerical equality; it does not retroactively mark the first attempt qualified.

Supplied assistant tokens and fixed continuation are not generated greedy responses. Vocabulary recognition of a pending EOG is not a natural EOG stop test. Fresh final-token replay for fully cached input, native trim-unavailable/failed common rebuild, cap/EOG generated terminal ownership, capacity extremes and broader placement/packing remain unqualified here.
