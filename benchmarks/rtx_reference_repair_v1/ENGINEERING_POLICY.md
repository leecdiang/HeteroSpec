# Agent freedom and boundaries

The user authorizes active implementation, ordinary engineering repair and gate-qualified progression in this new research stream. Do not merely restate the plan or stop forever at the first known counterexample. Do not repeatedly ask permission to fix compilation, paths, API drift, observation extraction, synchronization, source anchors or parsing. Record the change, test it, assign a successor build/epoch and continue within the shared budget.

## Permitted decisions

- Recover local authenticated assets and tools, reuse weights, build fresh code, and correct a source anchor after inspecting the actual pinned function.
- Diagnose prefill/continuation, select trace layers and logical positions, add a focused independent operand replay with native own-path controls, fix a real state/transaction bug, or implement a more appropriate operator-family repair when evidence rejects the supplied candidates.
- Choose candidate producer and row family policy from development evidence. The supplied family examples are not a required positive result.
- Recompute retained raw after an auditor bug without new forwards. Write an explicit correction; preserve prior claims/files.
- Adjust practical time/storage/cleanup reservations prospectively to the actual machine, before native starts, without an arbitrary overnight deadline. Exceeding the1200-request total needs renewed resource authorization.
- Create separate native-result/candidate-code PRs, evidence releases and verified access indexes. No merge is required to run the branch.

## Not permitted as a shortcut to PASS

- Changing R, weights/precision, prompt template, stop cap, tokenizer or output equality; deleting failed inputs or replacing the confirmation set after viewing outcomes without declaring exposure.
- Hardcoding task IDs, exact texts, model-name exceptions, token positions, expected answers or empirical logit-margin thresholds into inference policy.
- Calling a candidate value trace a natural timing sample, inferring device from buffers, treating a copied KV blob as copied logits/sampler state, or silently substituting a rebuilt reference that no longer matches the old executable.
- Resetting the shared ledger, overwriting old snapshots, removing a live ownership lock, or running concurrent workers on the same GPU.
- Advertising a fix after only the two known examples pass. New-input and original-model gates must run on the frozen implementation.

The Python host files use strict local identity checks. They are engineering protections, not an instruction to spend the project rebuilding supervision. If a check fails because it encodes a wrong metadata assumption, fix that assumption from source evidence; do not waive the scientific contract or re-interpret a counterexample as a PASS. Preserve the known PR156 placement error and correct it with scheduler evidence.

The default row-lowering helper is not a new general kernel and is not guaranteed to select the reference reduction. If it merely serializes the entire expensive path or loses performance, report that honestly and identify what arithmetic invariant or shared work a better implementation would need. Be mechanism-driven, not outcome-driven.
