# RTX B/C/D closeout study

This additive research tranche continues manuscript main e87291d and the completed Phase 2 A study in PR #60. It does not edit manuscript files or earlier studies.

The protocol was frozen before any new-task inference in private implementation commit 7b8c6fb. Complete inputs, exclusions and their hashes were frozen with it. HumanEval has no remaining unused tasks in the available project history; B therefore prospectively validates 24 previously unused sanitized MBPP descriptions. The claim concerns audited project exposure, not model training.

B completed 384 formal requests and 16 excluded warmups, following a 16-request/four-warmup old-probe bridge. All four conditions matched the repeated independent scalar reference on all tasks. C/D use the predeclared output-only target-scope selection rule. C/D execution is in progress; no closeout or cross-platform claim is made yet.

PROTOCOL.md specifies full-array/EOS gates, matched resident-request costs, width and length boundaries, reset qualification, failure retention and finite closeout meaning. Model weights, runtime binaries and raw telemetry are excluded from this PR. The complete local content-addressed archive will carry exact private source, raw evidence, frozen input/reference data and Git history. Public B_INPUTS.json contains only task descriptions, formatted prompts and zero-forward vocabulary tokenization, never dataset solutions or tests.

Restore the complete archive into a new experiment directory for execution. Prior Phase 1 and Phase 2 A archives are separate immutable dependencies. Configure HETEROSPEC_PHASE1_ROOT, HETEROSPEC_PHASE2_ROOT, HETEROSPEC_ASSET_ROOT and HETEROSPEC_RTX_STUDY_ROOT. The scripts require the exact bound private frontend and published CUDA runtime; they do not download weights or rebuild CUDA.
