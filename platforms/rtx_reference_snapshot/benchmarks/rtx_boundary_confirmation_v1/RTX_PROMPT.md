## 核心目标

PR120 中 QB 的核心优势有证据，但 q1 同图对照存在较大分块波动。本轮先确定
测量能区分什么尺度的差异，再确认几何边界；不预设 QH_C 必须胜出。

1. **CPU 入口与输入。** 运行 `python -B -m unittest -v test_cpu`，然后运行
   `python -B study.py --out <新运行目录>/plan.json`。计划包含参考、资格、A/A、
   确认和可选留出的任务；它不是可直接执行的原生入口。按 task 的 stage、
   optional 和 requires 分派，不能简单顺序执行全部任务而提前打开留出结果。
   实现 DATA_AND_RECEIPTS 的逻辑坐标数据生成和 stride 打包，先用独立标量
   检查向量化生成器，再固定输入/数值模块/host/分析身份。
2. **参考与数值资格。** 为新输入构建两次独立串行 q1 参考，保持完整KV与
   mask列。选定方法的完整52输入 × PQ/QB/QH_C 各做两进程重复资格。
   同时为另一个 observer 方法完成8个 A/A anchor 的 QB 资格。默认 H1 为
   完整资格方法；如果最后选择H0，需要补足H0完整资格，不能只凭anchor外推。
3. **A/A pilot。** H0保留 PR120 的逐调用观察；H1预分配输出与记录缓冲，将
   JSON/文件写入移出循环，仍保留每次输出、readback及精确检查。比较同一个
   QB 的两个标签A/B，每方法8 anchors、6配对块，平衡顺序。选择方法只依据
   正确性、A/A、实际可行性与预算，不能依据哪个方法让候选更快。正式确认前
   写 METHOD_DECISION.json。默认8 warmups +30测量；根据pilot可预先改50，
   用新计划、新hash保留原pilot；不能把原30次收据伪绑到50次计划。
4. **正式成对边界确认。** 24个q2/q4几何、2个q1控制，每个两种值模式。
   每个块执行 PQ、QB_A、QH_C、QB_B，两个QB标签必须传给同一个QB构图实现。
   8块分成两次实际采集session，每次完整4块；生成器保证各位置与相邻顺序
   平衡。分别只改变长度/GQA/Q存储/mask/头维度，不按旧结果获胜点挑选。
   保留每个几何自己的A/A，并用QB_B重算比较，不能挑两个QB中更快的一个。
5. **分析与可选扩展。** 导出经独立数值/证据检查的紧凑宿主收据，用
   `analyze.py --plan ... --observations ... --out ...` 分析；每种冻结计划和
   方法单独处理。输出宿主均值、块对比、同尺度A/A、两值模式及两session
   方向、完整缺失率和单因素边界。若还有预算，先冻结预测规则，再打开可选
   q3/GQA新几何与新seed；包括参考输出也须等待预测freeze。可完全不做留出。
6. **有稳定差异才追机制。** 可以用已有兼容profiler做少量独立诊断，不得和
   clean计时混合；30分钟无法准备就保留物理指标UNKNOWN。不要从图节点数
   推断kernel数，从逻辑bytes推断显存流量，或因发现局部反转就启动RTL。

## 自由度与诚实交付

可以修改工具调用、路径、构建、序列化、轻量监督、数据格式和执行适配器，记录
简短amendment。CPU helper 的代码若需改变，可以在正式数据前修改并重跑针对性
检查。不能改变旧参考含义、偷偷丢掉失败、修改正式块内数值语义或按延迟筛样本。
新runtime/新observer方法/新采样策略需要自己的明确冻结与资格，不与旧样本混合。

A/A噪声大不意味着停止所有研究：报告可分辨尺度，保留大效应判断，将小差异
标为未解决。分析器的A/A加阈值只是保守描述性筛选，不是已经校准的显著性检验。
缺profiler、只保留本地raw、CPU归档问题不应阻塞已经合格的无关结果。真实数值
错误或不确定的进程清理必须隔离或停止相应GPU工作，不能放宽正确性来解决。

不要求笔记本支持锁频或管理员GPU控制。按已定规则等待安静窗口，记录真实电源
方案和clock观察；只有首尾空闲时就明确没有持续独占证据。预算不足可以完成一个
4块cycle后交付描述性结果，不能称为完整8块确认；失败块与所有未启动任务保留。

复用PR120的硬链接上限修复，优先CAS+发生记录，避免制造十万必需硬链接。
raw不入Git；发布源代码、计划、紧凑生成表、RESULT.md、实际命令、原始位置与
hash/恢复状态。没有外部独立审查就不声称有。更新本PR顶部为真实结果并保持Draft。

本轮不执行自然decoder/actor/W1，不下载新权重，不开展RTL/FPGA，不改B570、
论文或main，不自动合并发布。最终回答：哪些差异超过测量波动；哪些因素稳定
改变映射相对成本；哪些局部反转消失；若仍无可靠硬件空间，明确保留HOLD。
