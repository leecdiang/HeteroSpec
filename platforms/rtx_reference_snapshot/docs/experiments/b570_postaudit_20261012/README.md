## 输出与端到端成本

费用比 = 左侧 arm 的时间 / 右侧 arm 的时间。每题每会话先取五轮中位数，再对两会话和 24 题等权几何平均。这里是事后配对分析，不增加独立任务数，不将 240 次配对当 240 个独立任务。

| 配对 | 完整输出一致 | 费用比 | MBPP | GSM8K |
|---|---:|---:|---:|---:|
| R_prod / M_match | 240/240，24/24题 | 0.988099 | 0.980665 | 0.995589 |
| R_prod / C_k1 | 240/240，24/24题 | 0.719264 | 0.695351 | 0.743998 |
| M_match / C_k1 | 240/240，24/24题 | 0.727927 | 0.709061 | 0.747295 |
| R_stock / C_k1 | 220/240，22/24题 | 0.731243 | 0.695257 | 0.769091 |
| R_prod / N_k1 | 170/240，17/24题 | 0.985591 | 0.981507 | 0.989692 |

C_k1 相对 R_prod 的费用增加约 39.03%，相对 M_match 增加约 37.38%；两种比较均在 24/24 题上费用更高。该结论覆盖原完整面板，没有剔除与 R_stock 不一致的题目。

R_stock 对 R_prod/M_match/C_k1 的差异仍为 GSM8K/test/1248 和 GSM8K/test/831，各十次；共享首差此前只是线索，本次完整数组核对才证明三者彼此相同。N_k1 对 R_prod 仍有七题不一致，不能仅凭 N 的费用较低宣称等价优化。

原先以 R_stock 为锚的预注册 `request_qualified_ratio=null` 保持不变。新增结论应标注“事后完整输出匹配的成本比较”，不能追认预注册通过，也不把 R_prod 与 R_stock 的差异归咎于 speculation 特有错误。共同 prefill 路径是待检验解释，尚未因果定位。

## 高接受率为什么没有带来收益

以下为 C_k1 全部请求的计数汇总；每输出 token 比率使用合计分母，不是逐请求比率平均。

| 指标 | MBPP | GSM8K |
|---|---:|---:|
| accepted_committed / proposal_verified | 88.82% | 87.48% |
| draft continuation rows / output ID | 1.0442 | 1.0612 |
| target verification rows / output ID | 1.0442 | 1.0612 |
| target micrographs（含 prefill）/ output ID | 1.0631 | 1.0690 |
| 输出长度中位数 | 40 | 128 |
| 达到 128 上限的题数 | 1/12 | 12/12 |

C 的物理 continuation width 全为 1：逻辑验证并未形成物理 target micrograph 数量上的节省，同时增加了 draft 工作。M 的 target micrographs/output 为 1.0。这个计数机制与负收益方向一致，说明高接受率不是充分条件；计数不能替代每阶段耗时，不能按行数假设等成本，更不能据此宣布普遍的性能上界。

GSM8K 全部请求到达输出上限，所以当前比较是固定上限工作负载的成本结果，不代表完整答案的任务准确率或长输出极限。MBPP/GSM8K 差异同时涉及长度与任务内容，不能仅凭两域差异断言长度的独立因果作用。

## 主线与后续动作

论文可将本结果用于“输出一致性、物理执行工作与收益边界必须分别验证”的主线：修复路径能与所测生产目标保持完整输出，但高接受率在当前物理分解下不足以抵消 draft 和验证成本。保留有界的负结果，比仅报告资格失败更有解释价值。

1. **B570 本轮证据可以收尾。** 不为翻正收益盲目调整 k、量化或排除题目，不重跑既有正式槽。把本事后分析与原资格结论并列展示；没有必要为论文主线要求所有路径先通过同一 stock 锚，才允许讨论任何成本证据。
2. **RTX 优先完成 PR91 已冻结的 confirmation 与原始档案收尾。** 随后用同一输出配对和工作量口径比较三家族，解释 R/M 与 M/C 分化；不把历史 Qwen 1.035× 与新面板的数值当优化前后因果对照。
3. **Break-even model 仍为 MODEL_TIMING_UNAVAILABLE。** 当前没有可辨识的 completed exclusive stage wall，保留计数解释，不拟合系数或报告预测精度。只有论文确实需要可验证预测时，再单列有预算的小型时间校准，并用未参与拟合的任务验证；不得通过给不可辨识时段分摊费用来“补全”模型。
4. **可选因果定位不作为当前收尾门槛。** 若需要宣称 prefill 导致 stock 差异，再单独冻结小实验：两道差异题，加两道长度相近但无差异题；固定 continuation、模型、输入、采样，仅干预 prefill UB128/512，先检查完整输出复现与方向。此结果只回答局部数值路径问题，不替代正式性能面板。
