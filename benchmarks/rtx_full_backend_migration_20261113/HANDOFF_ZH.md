# 给 RTX 执行 agent 的交接
请先完整阅读同目录 PLAN.md。任务是实现并准备完整 R/M deployment 对照，不是继续旧提取算子 U 或 C2。
本 PR 仅批准设计，不批准 GPU。先在 CPU 上定位 R 的完整运行入口、固定 M=0fb8f157、建立最小公共模型API adapter、测试 schedule/JSONL/统计和失败路径。不要加载 CUDA DLL、模型或创建设备 context 来做 CPU-only准备。
交付真实 R/M identities、模型与实际资源需求、可执行命令和关键依赖缺口，以及请求/rows/18部署/6小时/10GiB的独立预算摘要供用户一次审阅。不要强制证明4096全生命周期launch，更不要把旧500额度拿来跑新实验。
获得执行批准后按PLAN完成各自资格、固定工作P和自由greedy G两面板。保留所有结果、失败和差异；不追5%、不增加可选轮次。允许修普通工程错误，但不擅自换模型/参考/采样/计时合同。当前未授权运行；不得合并、修改论文或发布。
