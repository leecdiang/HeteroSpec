## Build

Requires TeX Live with latexmk, BibTeX, Times, AMS math, TikZ/PGFPlots, microtype, hyperref and xurl. No style modifications or page-compression settings are used. The official package is resolved directly from `vendor/official/mlsys2025style`; keep its untouched ZIP and SHA256SUMS.

From this directory:

```sh
make all
make hardware-only
make check
```

`make all` needs Python 3's standard library. `make check` additionally needs NumPy, pandas and pypdf; select an environment with `make check PYTHON=/path/to/python3`. It independently replays the 228 campaign checks and five selected-figure checks, preserves frozen bootstrap conventions, checks source/style/asset hashes and actual figure insertion widths, and verifies compiled PDF anonymity, font embedding, bibliography author completeness, and the main-page boundary. It never reruns an experiment or modifies frozen evidence. Figure coordinates and numeric TeX macros regenerate from the repository; quantitative edits belong in neither generated file.

`make hardware-only` excludes Section 7 at compile time. Its local verification PDF is `build/hardware-only/hardware-only.pdf`; the primary delivered version retains the reserved section. There are no references that require that section for the hardware story. Build intermediates and alternative verification PDFs are ignored. Both v0.3 deliverables are tracked; prior versioned PDFs remain unchanged.

The four main figures are M4 (Figure 1), the translation/boundary schematic (Figure 2), verification paths (Figure 3), and isolated-versus-realized state cost (Figure 4). The three quantitative PDFs use unchanged merged `../figures/style_v04/pdf/` assets.
