\section{Related work}
\label{sec:related}

\paragraph{Matching an existing numerical reference.}
Equality of mathematical operations does not determine their floating-point execution. Yang et al. reconstruct the bitwise behavior of cuBLAS kernels, describe the factors that determine reduction order, and enforce those factors in generated kernels~\cite{taming}. Their separation of arithmetic structure from scheduling already permits changes to output tiling and pipelining when the per-output computation is preserved. Their attention treatment is theoretical; the implemented reconstruction and verification focus on reduction and matrix-multiplication kernels. Our work addresses a different composition problem: executing quantized transformer queries against an existing reference while retaining the physical KV extent and persistent state that the surrounding decoder expects. The method couples compatible arithmetic groups with local cuts in the query sequence. We compose these constraints at decoder boundaries and test the resulting implementation under the stated deployment conditions.

\paragraph{Batch invariance and deterministic scheduling.}
He and Thinking Machines Lab identify batch-dependent reduction order as a source of inference nondeterminism and construct batch-invariant normalization, matrix multiplication, and attention~\cite{thinkingmachines}. Their attention discussion also explains how the boundary between cached and newly computed KV entries can alter arithmetic grouping. Thus, fixed reductions and the numerical significance of KV boundaries are established ideas. Our physical-range analysis asks which extent the selected reference actually uses, including initialized entries outside the logical causal prefix, and which query groups can share that extent without changing their arithmetic.

CoRun obtains deterministic inference through isolated prefill, fixed-shape batched decode, and position-invariant kernels~\cite{corun}. It coordinates execution shape, attention, collective reductions, and request-specific sampling state. This provides an alternative to making every kernel batch invariant. The relevant distinction is the chosen reference: a system can select a new internally consistent execution policy, whereas compatibility with an existing reference constrains which of those choices remain available. Our local cuts preserve such a reference at the points where combining queries would change it, while allowing compatible work to remain grouped.

\paragraph{Output and persistent-state obligations.}
Vosti specifies deterministic inference at the system level and verifies engine invariants together with kernel contracts~\cite{vosti}. Its central KV invariant ties every live or retained reusable cache entry to the value obtained from its logical token prefix. Layout, write isolation, kernel selection, and sampler state participate in the argument. This prior work establishes why determinism cannot be judged from emitted tokens alone. Our consumer obligations serve a related purpose for an existing implementation: they identify the output bytes and successor state that must agree before a changed execution can be reused downstream. We give a conditional composition argument and evaluate selected obligations, rather than claiming Vosti's mechanized system guarantee.

LLM-42 takes another route: a dynamically batched fast path generates candidates, and a fixed-shape verifier commits a consistent prefix or rolls back~\cite{llm42}. It replaces fast-path KV entries with verifier-produced entries even when token verification succeeds. Our construction instead organizes compatible execution before committing its results. This trades some scheduling freedom for avoiding verification and repair as the normal execution strategy. The two approaches therefore place their compatibility work at different points in the inference pipeline.

\paragraph{Quantized kernels and inference optimization.}
The implementation inherits deterministic quantized operations and four-column execution from \texttt{llama\_reproducible}~\cite{loop4code}. Modern \texttt{llama.cpp} also provides a few-row quantized matrix-multiplication path using integer tensor-core operations, asynchronous copies, and reuse across column groups~\cite{llama_cpp_fewrow}. We study the additional constraints that determine where compatible query groups can use packing and weight reuse. FlashAttention reduces memory traffic through tiled attention~\cite{flashattention}, while FlashInfer supports heterogeneous KV layouts and load-balanced attention execution~\cite{flashinfer}. Their optimization objectives do not require reproducing the bytes of the particular reference studied here. Our experiments separate comparisons within that contract from comparisons with a newer numerical path, so that the cost of retaining the reference remains visible.

\paragraph{Speculative decoding.}
Speculative decoding and sampling amortize target-model work by verifying several draft tokens together~\cite{leviathan2023,chen2023}. Their distribution-preservation arguments address a different requirement from retaining all outputs and persistent state of a fixed numerical execution. Liu et al. adapt verification effort to candidate uncertainty~\cite{liu2026heterospec}, improving how speculative work is selected. Our method concerns how selected queries execute once a numerical reference has been fixed. We report complete speculative-application comparisons separately from four-arm experiments that hold the draft policy fixed and isolate packing, local cuts, and their interaction.
