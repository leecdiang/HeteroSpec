# Optional C lifecycle qualification — design only, NOT_ADMITTED

The source-backed question is whether canonical token-LCP suffix repair can be
integrated without changing request tokens, reference results or real state
semantics. The saved compatible diagnostic has38 different partitions, not a
demonstrated system benefit. This permits at most a small engineering qualification
proposal. It does not justify timing or an N2 panel. All allowances below are new,
unapproved and nontransferable; no GPU action is queued or implemented here.

## Producer freeze required before admission

Use one mode, FREE_SEQUENTIAL_R, with the four source-only development episodes
already selected in PR224. Each has two fixed user messages, eight turn positions
total; no supplied assistant body is substituted for generated output. Candidate
arms must sample their own greedy output and build their own next request with the
same codec. R's expected tape is an oracle, never forced into a divergent arm.

Proposed producer basis is the pinned modern server full-message path, not legacy
completion and not an invented cache-preserving template. Bind its actual
content/reasoning parser, ID-to-text decode, returned EOG/CAP ownership, handling of
partial markup and user/assistant boundaries; store exact sampled IDs alongside
the parsed message history. Bind the original actual GGUF template bytes, all
template options and effective stops. In particular, use the declared nonthinking
mode, no tools, unchanged users, cap128, finite-logit greedy, no draft, one sequence.
Do not delete markup, append invented EOS or switch templates to manufacture reuse.

The upstream template engine is not presumed identical to N0's Jinja3.0.3.
Before a native run, execute CPU producer fixtures and compare canonical token
vectors for all saved N0 prompts and explicit EOG/CAP/thinking/special-token cases.
Pin exact parser/renderer/tokenizer source and artifact hashes and echo complete
effective configuration. If equivalence cannot be established, stop this proposed
unchanged-input route; do not silently relabel a different template as compatible.
This CPU bridge is not implemented or run by this successor.

Freeze cache_prompt=true, n_cache_reuse=0, ctx_shift=false, n_keep=0, one fixed
slot/seq0, no eviction/checkpoint import, no prefix compression and no extra
template/server stops beyond the declared EOG/cap reference. Verify what the
producer actually applies. If it necessarily applies incompatible stop semantics,
stop rather than suppress them silently. Unknown/ignored fields fail admission.

## Independent R, common repair and four arms

Build a separate Linux C4096 sequential R from the pinned reference arithmetic;
the original C1024 binary/source is preserved and cannot be made eligible by JSON.
Freeze R and repeatability before candidate output. One native context persists
through each complete episode, with stable context/sequence identity. A new user
turn does not reset it merely to make matching easier. Use Qwen3-8B-Q8_0 at its
fixed SHA, F16 KV, requested-output ownership, q32/P256 and output reserve32; bind
all actual source/modules/dependencies/flags. No upstream upgrade or Windows DLL.

The common C policy is in CONTRACTS.md: token-LCP bounded by actual materialized
head, tail trim, discard/reconcile pending, invalidate frontier and replay the
nonempty exact canonical suffix. Full cached input requires final-token replay.
Invalid cache/unsupported or failed pre-decode trim uses the same single full
canonical reset/rebuild for R and every arm, fully charged. A remains its frozen
negative control and is not changed retroactively. A native error after a decode
has begun stops the attempt; it must not hide a second rebuild or automatic retry.

Controls: whole-rechunk+loop4, whole-rechunk+packed, LOCAL+loop4, LOCAL+packed.
All receive identical complete append, repair, placement and legal optimization
opportunities. Record actual ordered outer calls, inner groups, physical KV
extent, graph/packing dispatch and rows; predicted head is not a native receipt.

Heavy qualification checks the entire actually requested vocabulary vector at
every output position, all36 layers of active K/V at declared lifecycle boundaries,
frontier validity/full vector, token IDs, sampled/stopped sequence, actual
materialized head, pending ID+position, trim/reset state and output ownership.
Bind the exact numeric comparator and inherited Linux qualification rules before
R; neither argmax nor final-token equality substitutes for them. No tolerance can
be relaxed after seeing a failure. The separate clean semantic bridge checks
tokens/stops/config/context/ownership plus terminal KV and declared frontier
snapshots. It is not all heavy intermediate checking and is not performance data.

An eight-request CANONICAL_ORACLE_REPLAY allowance independently rebuilds the eight
frozen R-produced canonical inputs, comparing full requested vectors and state
against resident R. It is a cold semantic oracle, not sequential R or a free
episode. This mode and its allowance are separate, with no pooling or transfer.
There is no other teacher-forced native panel or live timing allowance.

This is an upper envelope, not an executable operation manifest. Before approval,

after repair/reset with invalid-frontier flag, after canonical suffix, terminal
state and post-reset/ownership boundary. They are boundary snapshots, not every
generation step. A request that does not visit a boundary emits a declared absent
record. Capture at most132 complete requested F32 vocabulary rows in contiguous

## Window, supervision, failure and stop conditions

Propose one10-hour quiet window with an absolute final-worker-start cutoff6 hours
after start,4 hours reserved for compare/export/strict readback,2 CPU jobs maximum.
This is a watchdog envelope, not a measured completion forecast. A possible bound
is17 workers at15min (4h15),3 placement probes at2min,2h comparisons,2h export and
45min resource/coordination gaps =9h06. If the first bounded worker or storage
throughput cannot fit, stop partial without an extra calibration/model request.

Before every worker reserve enough time for its hard timeout and closeout, check
lock/process identity and exact ledger, resource allocation and interference. A
server-local noninteractive controller would use unique IDs, durable logs, atomic
STATE and no-restart-with-STATE behavior. A zero-GPU logout-survival heartbeat and
session cleanup-policy check precede any future execution; none is a model probe.
No such N1 controller is launched or promised by this CPU study.

Any numeric/state/producer/configuration/capacity/ownership failure stops before
timing. Resource pressure or interference pauses at a safe operation boundary;
unclear state, missing capture, exceeded budget, deadline or an error after native
work starts causes a durable partial/failed checkpoint. No infinite retry,
favorable rerun, quota borrowing or hidden reconstruction. A failed allowance is
not retry permission. Preserve all failures and raw costs. If producer support,
state equivalence or meaningful grouping disappears, close this branch honestly.

Admission currently lacks: implemented source-bound producer bridge, exact native
adapter/R/modules/builds, fixtures/comparator/capture writer bounds, registered
GPU UUID and quiet times, safe reserved storage/RAM, exact finite manifest and
explicit new GPU/request/placement approval. No request to execute is implied by
this document. Even a future N1 pass would require a separately frozen, separately
approved whole-episode N2 design before performance claims;5% is no stopping target.
