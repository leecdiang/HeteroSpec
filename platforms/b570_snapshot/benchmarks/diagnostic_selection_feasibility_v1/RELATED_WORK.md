# Bounded primary-source mechanism check

Accessed 2026-10-05. All four specified public arXiv abstract pages and versioned full HTML texts were accessible. The check reads the design/verification and stated limitations, not just titles or abstracts. Versions: LLM-42 v2 (2026-01-30); MarginGate v1 (2026-05-28); Stage-Replay v1 (2026-07-30); Integer Alibi v2 (2026-08-18). No additional works or private-result search queries were used. The arithmetic check reads the pinned upstream CUDA [vecdotq.cuh](https://github.com/ggml-org/llama.cpp/blob/0cae43063cf15170e91a2ff4d034da0ecef4a1b2/ggml/src/ggml-cuda/vecdotq.cuh) and [mmq.cuh](https://github.com/ggml-org/llama.cpp/blob/0cae43063cf15170e91a2ff4d034da0ecef4a1b2/ggml/src/ggml-cuda/mmq.cuh). Q8_0/Q8_1 helpers include integer dot products followed by floating scale products and floating accumulation of scaled blocks. Local files differ from public upstream bytes only in CRLF endings; raw hashes and this distinction are retained in ARITHMETIC_SOURCE_CHECK.json after the initial exact-byte assertion failed. This source inspection does not attest which helper/kernel every captured operation selected. Operand equality, full accumulator bounds and Vulkan arithmetic equivalence are unavailable. No W8A8 whole-layer integer-alibi conclusion is transferred.

The implemented P2 is ordinary qualified-proxy screening followed by direct actual-action verification. P1 would require additional state observations and would still need a reason that stage differences determine repair direction. This check provides no first/unique claim, and search absence cannot establish novelty. The defensible surviving result is a source-bound observability/cost audit and a bounded negative feasibility decision, not a new diagnostic-selection method.
