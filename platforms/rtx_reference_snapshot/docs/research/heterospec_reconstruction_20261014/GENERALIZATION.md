# 普适性路线：按条件迁移，而不是按设备数量外推

**本文件是分析模型和未来验证设计；不实现在线控制器，不授权新实验。** 所有预测均为数据知情的候选假设。数学推导是解释用的充分条件，不声称新定理或正式验证工具。

## 1. 用同一对象连接两平台

令 `p` 为已经消费的逻辑 token 前缀；`s` 包含 K/V、位置、pending token/有效 logits、sampler 及其他会影响后续输出的状态；`g` 是实际执行几何和图表示；`F_g(p,s)` 是一次已定义边界的计算。对 speculative decoding，边界应放在完成 acceptance、correction/bonus 与 rollback 之后，不能把未提交 proposal 当成参考前缀。

需要分开检验：

- **算子/几何比较**：固定 `p,s` 和真实 operand，只改变 `g`。PR98 replay 属于此类。
- **状态形成比较**：固定 prompt、精度和 receiver 规则，只改变 prefill 的实际分段，再观察形成的 `s`。PR99/101 属于此类。
- **状态干预比较**：固定 receiver、初始 logits 和直到被比较位置的前缀，替换已形成状态的一部分。PR103/105 属于此类。

一个类别的成功不能替代另一个类别的成功。CUDA 对 QB 的正面证据与 Vulkan 的 producer/state 反例并不是一项完整跨后端2×2；该空缺应明确，而不是以“有两张卡”代替。

## 2. 为什么只约束消费者可能不足

写整个局部流程为 `D_g(P_g(x))`：`P` 形成进入局部区域的状态，`D` 消费它。只证明在参考输入 `s_ref` 上

`D_QB(s_ref) ≈ D_ref(s_ref)`

不能推出

`D_QB(P_fast(x)) ≈ D_ref(P_ref(x))`。

缺的是 `P_fast(x)` 与 `P_ref(x)` 对后续计算的相关性条件。B570表明：单query continuation仍能区分不同prefill形成的KV；而两个完整状态在cap128内输出相同，也不保证它们的分量混合保持相同输出。[S05,S09–S11]

这里不是断言“状态只要不同就必然失败”，也不是断言“字节相同是必要条件”。状态可以不同而产生相同端点，也可能由后续计算抵消。需要识别的是：**论文到底证明了哪一类等价，以及在什么边界下保持它。**


## 2A. 将状态边界转成两个具体、可反驳的技术要求

PR102 区分数学、局部数值和完整端点三层。本次建议增加第四个问题：**某种已观察的等价关系，能否被局部变换安全组合？** 这是对基线证据问题的扩展，不是声称发明了程序等价或组合验证。

固定 receiver、初始采样契约与有限时域 H，记 `sA ~H sB` 为完整可见端点相同。不能从此推出所有选择掩码 M 都满足 `Mix_M(sA,sB) ~H sA`。PR103 的 /1011 直接给出反例：完整 A/B 等价，某些混合态产生第三轨迹。/1249 则保留为混合后也稳定的反例对照。[S09]

另一个集合论问题是：若掩码 M 能复现 donor 端点，是否每个超集 M' 也能？/1248 B→A 的 V0→K0∪V0 反例说明，该面板上的“充分掩码集合”不是向上封闭的。[S09–S11] 因此，任何依赖此单调性的二分或贪心扩大策略，都不能仅靠这些数据保证正确；这不是证明所有搜索策略都无效。

这两条有限反例给出的实际价值是：**局部数值修复或缓存替换的准入，不能把完整输出等价当成组件可互换证明，也不能把加入更多受约束组件当成必然更正确。** 它们将 B570 从一般的“误差存在”推进到可检查的组合性义务。是否覆盖真实运行中的新输入仍需前瞻验证；人工混合并未被证明自然可达。

## 3. 一条有用但不新颖的条件性归纳说明

设候选与参考在对应提交边界满足某个已定义状态关系 `R(s_c,s_ref)`，并假设：

1. 初始前缀、相关状态与随机性/greedy选择条件满足 `R`；
2. 对每个允许的下一次事务，候选与参考发出相同已提交 token/停止结果，并在 reconciliation 后再次满足 `R`；
3. phase/role、图复用和状态恢复没有绕过上述事务条件。

则按提交事务次数归纳，在该允许执行集合内，完整可见输出一致。一个强但非必要的 `R` 是相关状态逐字节相等、后续数值操作对应；更弱的关系需要另外证明其保持性。

此说明的作用是标出证据义务，**不是把假设本身当成结论**。测试有限输入只给有限经验资格；与 Vosti 的 Verus/relational-kernel 证明不是同一证据等级。[P03] 精确算术的 query-view 等价也不能自动满足有限精度的事务前提。

## 4. 将“普适”拆成三个层次

| 层次 | 可带走什么 | 现在的状态 |
|---|---|---|
| 数学表示的一般性 | 在 query 可分、mask/head/KV语义对应条件下，序列内query-axis可以提升为独立attention batch轴 | 基线已有索引论证；不依赖GPU品牌 |
| 工程适用域的一般性 | static guard、状态来源、图身份、输出/成本资格可形成统一接口 | 本文重构提案；未形成通用自动工具 |
| 实证迁移的一般性 | 未见输入、长度、query geometry或另一后端上维持预先声明的资格与收益 | 当前不足；不能用旧校准输入循环认证 |

Qwen3、SmolLM2、Llama扩大模型覆盖，但后两者有相近图路径，不能称三种完全独立架构。B570扩大状态边界证据，但没有QB/Vulkan成功实例。q>4、FA、MLA、MoE、多stream、多GPU、随机采样，均不能继承当前数值结论。[S03]

## 5. 建议的“可迁移修复画像”接口

这是一种研究/制品接口，**不是已运行的在线决策器**。一份画像必须包括：

| 字段组 | 必需内容 |
|---|---|
| 参考 | 模型/tokenizer/格式/采样/停止规则、ordinary recipe、有效时域 |
| 实际几何 | occupied q、key extent、caller widths、micrograph分割、output reservation；不能只记UB |
| 逻辑语义 | stream ownership、Q/mask真实stride、GQA映射、bias/sinks/RoPE支持、输出次序 |
| 状态来源 | producer phase/recipe、前缀/位置、必要边界状态、恢复sham与来源映射 |
| 图身份 | role/phase activation、cache key、counts-off路径、拒绝域 |
| 资格层级 | 数学合法/同输入数值测试/完整端点/不确定/已反例，分别记录 |
| 成本 | PQ/QB，GS/局部，同布局M/C，计时通道、任务/时间块依赖 |
| 暴露范围 | 校准与未见验证分离、精度/backend/build变动、外推禁止项 |

画像的关键不是增加hash。PR104 binary routing和PR105 registry错误已经说明：所有文件各自hash正确，不等于逻辑cell被分配了正确对象。身份绑定必须追溯到真正被调用的执行对象；但这属于实验准入质量，不应被膨胀为论文主要创新。[S12]

可复用决策流程应输出三态：`QUALIFIED_ON_RECORDED_DOMAIN`、`DISQUALIFIED_WITH_COUNTEREXAMPLE`、`UNRESOLVED`。缺少证据不能转成PASS；被拒绝也不必说明方法在该域绝不可能成立。

## 6. 什么才算新增“预测性普适性”

仅把旧结果解释得更好，是回顾性解释；不是预测性验证。建议未来在单独授权、单独注册下执行以下最小链条：

**校准阶段**：仅使用已暴露输入、模型源信息及已有replay，冻结候选支持域和资格预测规则；规则不得调用未见验证的endpoint来决定是否“预测成功”。例如静态非法域直接拒绝；静态合法但无状态/数值证据的域标UNKNOWN，不能默认通过。

**验证阶段**：预先给出一组新输入/形状边界，先由画像输出接受/拒绝/UNKNOWN，再独立运行参考与候选。报告接受覆盖率、被接受域中的反例、拒绝但实际可能成功的情况，以及同参考成本。不能只报告最终通过的任务速度。

**域变更测试**：换 key extent/实际分段、mask pattern、phase/graph复用条件时，分别测试静态保护和数值保护是否仍成立。q=1作为共同路径负对照；padding和mask语义必须保留，不能为了数值好看改输入。

画像还必须击败两个平凡基线：全部拒绝（错误接受为零但覆盖为零）以及静态shape合法就接受。仅凭完整hash允许原recipe，不构成有效迁移；必须在未见但预先声明的形状/输入变化上获得非零覆盖，并同时报告误接受、UNKNOWN、资格检查开销和总请求成本。不能用拒绝所有难例换取“普适正确”。

这是一条可产生超出“多测几个模型”价值的研究路线，但尚需画像规则的可实现性审查。不能把未来协议称为已有算法。初始 E1 的72 contexts不等于这一前瞻验证，也不能在其执行中临时扩预算。

## 7. 新的零GPU分析建议：决策相关差异应对共同logit平移不敏感

完整残差向量 `R = z_joint-z_first-z_second+z_EMPTY` 非零，可以证明原始logits的非加性，但若 `R(v)=c` 对所有v相同，softmax/argmax不变。**大向量Linf或“全部元素非零”不自动表示决策相关的交互。** 当前 `/1248 t47` 的pairwise残差非零，已避免这个最简单歧义；其他位置仍建议同时报告对平移不敏感的量。

建议在已有full vectors上计算 `R(v)-R(r)` 或振幅 `max(R)-min(R)`；保持所有旧值，新增列，不覆盖原定义。这些是标准的对比量，不包装为新理论或在线算法。

同理，若 `delta=z_candidate-z_ref`，参考top1的最小margin为m，则 `m > max(delta)-min(delta)` 是该已观察位置保持top1的一个充分条件：每个竞争者相对原top1最多获得delta的振幅。它不比逐个竞争者检查更强，也不保证未来位置。原来的 `m>2||delta||∞` 是较保守的充分条件。

**关键限制**：这需要参考和候选两条已观测完整向量；不能作为无参考的免费在线触发器，也不能以本推导宣称超过 MarginGate。[P04] 本PR只提供分析建议，不声称已经重算54个raw向量；目前环境未获得该私有子包。

## 8. 下一轮实验优先级：信息增益而非请求数

### 已有计划先完成（不在本PR执行）

- RTX E2最终session与完整分析，保留先验1.02阈值、依赖单位和所有任务回归。五个同日session好看不等于跨日保证。
- RTX E1隔离编译、真实参数传递、counts-off/control、native own-path与replay重复。实际kernel/reduction tree未知时，停在可测层级。
- B570 v2在执行器/账本/watchdog/执行F0完成并获作者授权后，保持原168 starts矩阵。重点缺口1011 t9/10、831 recipient A L0 t39/40和1249后续位置，但不据此删除其他预定坐标。[S08,S10–S12]

### 两项可带来额外创新的独立后续

**G1：前瞻适用域验证。** 目标是检验画像能否预测“在哪些条件下局部修复可用”，而不是进一步拟合旧的四个任务。对比最简单的“静态形状合法即接受”规则，报告错误接受与UNKNOWN；这是检验方法实用性的最短路线。

**G2：干预形成过程而非只拼最终状态。** 区分直接patch序列化KV与在V reshape前/K RoPE前替换投影输出、让下游自然重算两条路径。必须先解决alias、生命周期、同步、F16 cache-write来源、own-path sham与observe-off。它可加强投影→状态→决策的解释，却仍不自动证明自然可达性或唯一kernel。[S10,P09]

G2尚无合格hook；不能通过放宽旧guard把它变成“已经就绪”。G1和G2可先作为研究设计，是否值得实现由已有实验完成后的信息缺口决定，而不是为追求更高录用率无限加实验。

## 8A. 竞争假设与判别结果

| 候选解释 | 与竞争解释的区分 | 需要的判别证据 |
|---|---|---|
| QB减少显式PQ图结构成本，而非数值工作全部减少 | 温度/执行顺序可制造同方向小差异 | 独立时间块、任务回归、q=1负对照；没有合格组件时间就不定位launch开销 |
| 状态总误差范数足够解释端点差异 | 相似幅度沿不同方向响应和margin导致不同结果 | 本次四输入排序已反驳完美单调阈值；未来未见输入才可比较预测器 |
| 端点非单调只来自可加分数越过argmax | 实际联合分数具有非加性 | 同前缀四格已经在1248 t47排除该四格的精确可加解释，不排除其他机制 |
| POSITION残差反号表示机制反转 | 同四个状态和相反token坐标的代数换位 | 已有字节规范化支持后者；保留进程重复但不重复机制计数 |
| 某个上游投影差异足以解释所选状态/后缀 | 末端混合有效可能依赖不自然的组合 | 合格投影注入＋下游重算＋cache-write来源链；现有结果尚不能判定 |

## 9. 外部baseline：两级比较，不偷换参考

**第一级（本论文已有）**：同栈、同模型、同精度、同ordinary reference的PQ/QB/GS比较。回答具体图表示增量。

**第二级（新增价值仍待验证）**：将最接近的固定形状/额外verify路线适配到同一参考契约。不能直接把CoRun/LLM-42论文中的不同硬件吞吐率与本机延迟并排排名。适配不等于完整复现原系统；不合格时报告输出不一致及成本不可比，不修改参考到其刚好通过。

若本研究不做第二级，贡献应明确为in-stack design comparison。若要宣称系统优于近期方法，第二级是必需工作，而不是加几条引用就够。[P01–P04]

## 10. 普适性的最诚实且有用表达

别人目前能够复用的是**图变换的实现条件、区分producer与consumer的分析方式、同前缀四格与坐标规范、以及把参考资格和经济性分开的比较方法**。别人还不能直接复用的是“任何模型/后端都可开启QB”的保证。

因此，论文的普适价值可以先是**可迁移的问题分解与可否证接口**，再通过未见条件验证升级为经验泛化。不要用漂亮的条件定理代替真实覆盖，也不要因为当前覆盖有限就放弃提出具体、可测试的新方法。
