## RTX 新结果实际填补了什么

**A 填补同集竞争候选缺位。** 在 19 个曝光审计后剩余提示上，预定义 target-only UB2 为 51/57，H2 与 fresh replay 各 57/57。UB2 和 UB1 reference 虽同为 51/57，却分别失败于 `/15,/25` 与 `/15,/18`。因此是指定候选被否证，而不是两个参数名或总计的重复展示。Replay 的成功不证明 proposal/history 对全部程序必要、最小或唯一；H2 用 draft 构造反馈依赖的 tape，且程序共享数值例程。

**B 填补资格与成本跨研究的问题。** 同组提示上的 171 个新三路径运行，用自己的直接 ID 门与统一计时边界：batched 51/57 BLOCKED；serialized 57/57 QUALIFIED，target/serialized GM 0.677351，CI [0.661653,0.691812]，0/19 更快。结果支持排除被测 instrumented serialization 作为延迟优化。它不证明无日志部署更慢，也不为 blocked batching 形成合格 speedup。旧 0.646 是另一队列，不能解释成改进趋势。

这些结果提高了论证完整性，却没有增加普遍机制、独立数值实现、生产速度或总体外推。19 个 prompt 不是 57 个独立任务，A/B 也不是两组独立样本。

## 主轨风险与优先修订

最强接收理由是 B570 能在 live 前预报完整非参考轨迹，RTX 用同集失败候选提供可反驳边界，并在同研究里联合判断资格与成本。最强拒绝理由是其科学增量集中在共享数值栈、一个模型家族与少量真正区分的任务上；工程决定多为配置否决，尚未给出足够清楚的可复用诊断约束。证据管理很严密，但严密本身不是新颖性。

以下均可从现有材料完成，详细追踪见 [修订优先级](REVISION_PRIORITY_V087.md)：

1. 统一贡献顺序，以完整轨迹前瞻预测与同集判别为科学主线，以匹配资格／成本为系统后果。明确“原资格失败已知道什么”与“预测结果才新增什么”。
2. 给 UB2 和 replay 一个紧凑输入／执行假说说明；将 `/15,/18,/25` 的交叉关系直接放在 Table 3 附近。共享数值例程应和编排独立同处说明。
3. 补 V4 自己的绝对 prompt-median 延迟尺度；旧附录 A17 属于 30-prompt 研究。不得把绝对分布中位数之比替代原 GM。
4. 说明 V4 bootstrap 条件于已选曝光队列、已观测中位数与冻结配置，按经验提示分布重采样；不认证总体、曝光选择或新会话。
5. 收紧 `causal and transfer limits`、`mechanism-validation` 等概括；把 B570 score delta 和现有 margin 尺度邻近呈现。压缩历史 inventory 与重复边界，修复浮动插断句子／旧 estimate 的阅读问题。
6. 准确区分旧两条件成本与新 V4；修正附录入口交叉引用；用小表说明最接近先行工作的重叠与本稿增量。

主代理已重新打开并检查 R2 的四篇原始论文相关部分：[Lossless but Not Free](https://arxiv.org/html/2607.17283v1) 的 correctness gate、target-only batch-shape 现象和成本测量；[LLM-42](https://arxiv.org/html/2601.17768v2) 的 shape-consistent verifier 与 KV repair；[Numerical Sources](https://arxiv.org/html/2506.09501v2) 的系统配置／浮点路径敏感性；[Correctness Forensics](https://arxiv.org/html/2510.22876v4) 的同步错误和残余数值差异区分。这个有限核验支持“重叠很大，增量需聚焦”的判断；不是完整相关工作审计或全球首次认证。

上述请求尚未写进冻结稿件。不能拿本轮评分描述一个随后改过的 PDF；后续修订应生成新的成品身份并对变化作针对性核验，不为获取更好分数重复收集六轮投票。

## B570 决策

**本轮不执行新的 B570 实验，不做 dense scan。** 当前论文没有把 18/72 persistent-UB128 的后续差异归因于那个单块，也没有声称 hidden-state 因果链被识别，因此缺少 single-block/common-policy 对照并不推翻已写结论。六份评审全部认为新增执行不是现有限定主张的必要前提。

若作者明确将论文提升为“单块 partition 改变足以导致即时或延迟离散决定差异”的更强因果贡献，再考虑一份新的有界协议。其科学价值是消除持续后续策略这个混杂，不是扩大数据量；它未必改变 R1 的重要性判断，更不能预设产生 positive witness。详见 [B570 决策与触发条件](B570_DECISION_V087.md)。

当前建议顺序是：交付本次整合和精确审稿 → 作者决定现有材料修订 → 评估修后论证是否仍需要主动追求更强因果贡献。358H/M4/RTX 研究继续 CLOSED，不把限制节视为扩实验授权。会议规则、arXiv／公开发布和最终提交仍是独立决定。
