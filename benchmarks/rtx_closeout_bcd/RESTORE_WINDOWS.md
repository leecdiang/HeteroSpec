# RTX 完整记录包：Windows 恢复说明

完整 ZIP 已通过 CRC 与全部内容对象 SHA256 校验。本次另实测恢复全部 **10,151 个文件**，恢复绑定的四个私有可执行程序与已安装发布 DLL，并对四个程序执行版本检查，全部成功；没有加载模型或增加模型前向。

默认深目录恢复第一次遇到 Windows 路径长度限制：原生源码包含层级较深的前端文件。保留已恢复且哈希相同的文件，改用 Windows 扩展路径前缀后，原恢复程序成功恢复全部文件，无需修改 ZIP 或实验代码。

在 PowerShell 中，为恢复目标提供绝对路径，并加上 `\\?\` 前缀，例如：

```powershell
python rehydrate.py '完整记录ZIP的绝对路径' '\\?\C:\你的恢复目录'
```

请将示例路径替换为实际目录。前缀后的路径使用反斜线；恢复程序会逐项核对长度和 SHA256，拒绝覆盖内容不同的文件。使用新的恢复目录。运行 `rehydrate.py` 需 Python 3.11；它保存在 ZIP 的根目录，不需要先恢复原生源码。

恢复后配置旧阶段和资产目录：`HETEROSPEC_PHASE1_ROOT`、`HETEROSPEC_PHASE2_ROOT`、`HETEROSPEC_ASSET_ROOT`、`HETEROSPEC_RTX_STUDY_ROOT`。Phase1 和 Phase2A 记录包是单独不可变依赖，身份在 ZIP 的 `INDEX.json` 及校验文件中保存；本轮 ZIP 不重复嵌入它们。

在恢复的 `experiment` 目录运行 `restore_runtime.py`，核对并放置绑定的私有程序及已安装发布 DLL。模型权重、发布运行库需要另行提供并与绑定哈希一致。图表分析另需 NumPy、Matplotlib。私有前端保留原 CUDA 发布库，本公共研究目录不能单独重建任意 CUDA 版本。

恢复与证据复核不等于重新执行实验。若重新运行模型，需从 `generated/FROZEN_HISTORY.bundle` 创建独立的新工作目录，重新冻结输出目录和执行清单；原程序有防覆盖及干净 Git 版本检查。不要在原记录目录上覆盖执行，也不要在这些任务已被执行后重做“未执行任务”的筛选。

ZIP 冻结的本地源码版本为 `250058d62ff4c335374ba94b31520f8a7a347182`。本说明及恢复校验是在打包之后补充的交付记录，ZIP 未被重写；GitHub 后续文档提交可能晚于该源码版本。所有在线实验仍绑定各自清单中的冻结版本。

这份记录只覆盖 RTX 的有限实验。B570、功能正确率、多并发吞吐、普适无损及最优宽度均未由本包验证。
