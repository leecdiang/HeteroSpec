# Common protocol and execution freedom

## Four phases, independent per lane

**G0 inventory/admission.** Resolve real old binaries, source kits, model files and original masks/lifecycles from manifests. Check available memory with signed/bounded arithmetic; no unsigned `free-reserve` underflow. Record actual device/driver, loaded libraries and relevant environment. Compare module lists before/after representative calls to catch observed lazy loads; this is a reproducible local deployment record, not proof of every possible dynamic load. Verify the original binary remains unchanged. Do not require recovery of the lost cloud scratch directory to perform new host work from verified sources.

**G1 old-R / observer bridge.** Run unchanged R and the observer derivative on the same historical inputs, producer caller lengths, output-mask policy, output reserve, context capacity and resident-reset/fresh lifecycle. Repeat natural R to check stability. Only read rows already requested by each call. Compare all available old-R full vectors and endpoint against observer-R; add separate active-KV/frontier readbacks at corresponding logical prefixes. If the old worker did not capture KV, explicitly label the new observation bridge—do not retroactively claim old raw KV exists. Validate exact writer format and layer order with source pins plus sentinel fixtures, then compare actual payload values with an independent scalar producer. Same serializer source alone is insufficient.

**G2 mechanism/eligibility and small development pilot.** Use exposed development inputs for errors and mechanism, not confirmatory claims. Keep all attempts. Actual candidate target verification can consume a different proposal tape: create forced-reference jobs from its token prefixes, not its values, and also run an autonomous reference which never receives candidate endpoints or forced tapes. At terminal accepted stops the frontier is the retained-prefix row, not necessarily the last-logit API value. Initial/correction/bonus stops may leave one emitted token unmaterialized. CPU branch fixtures support the controller; do not require a trained-model natural j2 rejection before testing a valid deployed arm, and do not manufacture a trained model's rejection by changing weights. Record absent natural branches honestly.

**G3 frozen natural confirmation.** Freeze source/executables, input selection rule, admitted arm roster, complete service window, costs and analysis before new outputs. Default four development and twelve test roots per lane/family, with no overlap with prior project-exposed roots. Reuse the pinned public pools already on the host; prefer the same original-host tokenizer/templates. Select uniformly by root then one path/root; do not pad, truncate, sort by measured speed or optimize cut offsets. CPU selector assumes the host has supplied genuinely admissible metadata. If there are too few eligible roots, amend selection before any test output, retaining the limitation. Do not make the other platform wait for a common blind gate; these are complementary studies, not a pooled GPU comparison.

## Comparisons and timing

RTX operator: graph_tiles / backend_loop4 / packed, same target/draft/caller policy across arms. Primary paired geometric complete-service ratio; total-service ratio also reported.

RTX draft: M / D1 / D2 / D4, target unchanged. B570: M / C1U1 / C4U1 / C4U2 / C4U4. Primary total complete-service ratio, compared with **all** fixed controls; equal-root log-ratio sensitivity is secondary. M is an equally optimized target-only baseline; initially preserve the same weight residency/context policy when isolating speculation. An independently admitted target-only-with-draft-unloaded deployment is separate, not spliced into the main estimator.

Every measured slot has immediate same-arm warmup; all slots and attempts stay in the ledger. Counterbalanced orders are generated in `design.py`. Each logical paired session contains its full scheduled sequence. Preserve resident construction/reset and priming history exactly as declared. Sequential version-specific worker processes are allowed when numerical libraries cannot coexist; do not force all model copies into GPU memory. Re-establish and qualify the same admitted priming history on restart, record loads separately, and never silently charge cold context creation as resident-reset or vice versa. Where old lifecycle uses fresh contexts, create/destroy them inside the same service window for every arm.

Separate synchronized operator/phase diagnosis from clean service measurements. Service includes actual reset/create, target+draft prefill, proposals, verification, sampling, trim, necessary sync, required guard/restore and response commit. Never subtract geometric cumulative clocks to manufacture a phase. Record model loading/provisioning, offline qualification, engineering and artifact delivery separately; do not double-count them. Diagnostic full vectors/states are not charged online if they do not run online; any actual online check/fallback is charged. Report first-use and steady-state appropriately; retain graph capture/replay/fusion where the compared deployed modes legally use them.

The analyzer returns every fixed contrast with root-cluster intervals and reports both aggregate estimands. Repetitions are not independent workloads. Tail p95 from twelve roots is descriptive, not an SLA claim. A null or reversal is not a reason to add sessions. No 3% or 5% pass threshold.

## Scope of qualification

Heavy diagnostic runs compare actual target vectors, committed active target KV, positioned unmaterialized suffix and retained-prefix frontier. Hidden padding/allocator/driver closure is not proven. Heavy/off observer bridging must establish unchanged outputs and final state on the finite admitted domain before clean timing. A missing state payload is unverified, never a zero-length successful state. Validate reference values, not just hashes of self-declared descriptors.

The supplied capture format checks **all recorded boundaries**. For storage, the host may use content-addressed chunks/streaming comparisons and retain deterministic reconstruction plus compact examples/failures, but must explicitly state which raw payloads are available. An offline audit summary is not a substitute for executing the original independent reference. Do not silently widen a synthetic parser profile or promote an old endpoint-only run to a full-vector/state validation.

## Engineering freedom and scientific stop rules

The agent is expected to fix paths, compiler versions/headers, linking, ABI adapters, source anchors, telemetry normalization, resource polling and test harness bugs autonomously **during development**. Record before/after hashes and the failure. Code changes that touch numerical paths need new local qualification. Use fresh output trees. Reuse already verified old runtime code rather than rebuilding all of PR179/182.

A missing file or a stale documentation label is not by itself a research stop: resolve it through the fixed source kit/PR and continue the independent lane. Do not continually ask for confirmation for ordinary engineering work within this task.

After test outputs begin, do not tune policies/arms/inputs. A numerical bug invalidates that version's confirmation; retain it, fix in development, and freeze a fresh cohort/version within the overall budget. Environmental interruptions may justify one **whole-session** retry, with the incomplete attempt retained and independently reported; never retry just the slow slots. Do not silently pool across versions. No new hardware purchases or paid compute are authorized.

If an arm cannot fit, correct the admission arithmetic first. Ineligible optional UB arms may be omitted only before confirmation, with explicit capacity/numerical status. Required controls cannot be removed because they are fast. If M or the unchanged draft path cannot fit, close that lane rather than relabel another residency/context as the old deployment. Continue other viable lanes. A narrowly declared different deployment needs its own original frozen reference and is a separate secondary result.

## Resources

The initial planning ceilings are **RTX 8,192 model requests / 16,000,000 decoded token rows / 8,192 isolated operator replays**, and **B570 6,144 / 12,000,000 / 2,048**. These are conservative ceilings, not required expenditure. Count each fresh or resident-reset reference trajectory as a request, including forced-prefix replays, development, failures and warmups; count every actual decoded token row, including rejected branches. Batched controller jobs do not hide reference work.

Before native launch, the host estimates worst-case work for its actual prompts/forced-prefix branches, sets finite memory/disk/wall limits, and assigns smaller per-stage reservations. `runner.py` reserves before process creation. A practical short capacity/bridge failure should end cheaply. The agent may redistribute budget between **unstarted** lanes or reduce a confirmatory cohort prospectively (at least eight roots for a main claim), documenting the amendment; no increase to the overall ceiling or post-outcome power chasing. Do not reserve the entire ceiling for every session.

Use actual storage estimates; raw state grows with active prefix. Prefer deduplication/streamed comparison to massive repeated snapshots. An 8 GiB legacy dump guard is not permission to disable resource limits; implement a bounded appropriate replacement before freeze. Stop at host resource limits and deliver partial status, not fabricated completion.

## Deliverables

Each result PR must include the fixed original references, precise deltas, real execution/method trigger checks, qualification scopes, all planned slot outcomes, raw availability, independent recomputation instructions, complete costs, strongest same-contract comparison and paper disposition. Keep the prior AUTO/QB/WB negative evidence. No merge, paper edit, arXiv replacement or rented GPU in this task.
