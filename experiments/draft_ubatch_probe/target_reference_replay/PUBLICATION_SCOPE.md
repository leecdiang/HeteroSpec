# Publication scope and data provenance

This is an additive publication of the independently reviewed offline replay-design package under PR183's `experiments/draft_ubatch_probe/target_reference_replay/` only. Existing workers, numerical libraries, model files, archived journals and other PR directories are unchanged. The pre-publication `DESIGN.md` and independent reports are preserved byte-for-byte; statements there about no PR write describe the completed investigation before this additive publication.

No GPU execution, user device access, new neural-model inference, runtime replay implementation, deployment admission, merge or performance claim is included. The auditor always reports `gpu_qualification_established=false`. Fresh-context R does not automatically equal historical resident-reset R. Resource counts are modeled token/byte accounting, not measured GPU speed or compulsory storage.

## Data provenance

- `example/` is completely artificial, generated by `make_artificial_example.py` and `test_replay_audit.py`. The prompt is the deliberately constructed integer list [1, 2, 3]; the tiny vocabulary, proposal tokens, logits, identity digests and fake KV bytes come only from that deterministic test generator. Fake KV is packed token integers, not model state.
- Independent cases and historical counterexamples use the same artificial vocabulary/function plus independently generated control-flow traces. They contain no user prompt or third-party private data.
- `journal_plan_published.json` contains aggregate planning counts and source-file hashes for the already-published PR183 synthetic CPU fixture journals. Their prompt is the source-code constant [1, 2, 3, 4, 5, 6, 7]. No natural-language prompt, user-derived token sequence or private-data hash is included. Those input journals themselves are not copied into this directory.
- `SOURCE_MANIFEST.json` binds already-published synthetic journals/receipts. Other manifests bind only the code, documents and artificial artifacts in this package. Model identities mentioned in documentation come from the published synthetic fixture receipts; architecture cost estimates cite public vendor configurations.
- No original user prompt/token, third-party private content, or derived digest of such content is exported by this publication.
