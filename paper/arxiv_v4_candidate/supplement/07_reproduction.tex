\section{Reproduction and evidence access}
\label{supp:reproduction}
The source package builds the article and supplement from \texttt{main.tex}. It includes editable figures, reported cost/state matrices, original RTX session tables, later service blocks and recovered E2 request times. The later transfer, prefill and matched-deployment records are pinned separately (\sref{supp:followup}). Analysis scripts reconstruct the registered estimators, absolute request costs, repair--draft contrasts and session sensitivity. Source hashes bind copied inputs to their campaign records. Original derived summaries permit one adjacent binary64 value for platform rounding; the later reconstruction uses an absolute tolerance of $10^{-12}$. Source bytes, integer counts and generated TeX remain exact.

\texttt{anc/runtime\_reproduction/} supplies CPU interface tests and archived implementation sources/patches with provenance. These expose the query/mask mapping, phase/cache contract and scoped AV repair. The companion native kits now add build routes, real fixtures, replay commands and execution receipts for both platforms~\cite{rtxnativebridge,b570nativereproduction}. RTX rebuilds the core and frontend from authenticated source while retaining pinned CUDA/BLAS and ggml numerical libraries. Its real $q=3$ fixture reproduces original and rebuilt QK/softmax/AV bytes, and complete HTTP requests reproduce the historical endpoints. B570 rebuilds all five numerical libraries and 147 shader translation units without old object directories. Its real $q=2$ stage fixture and four-input R/PQ/QB panel reproduce the declared stage bytes and 914 corresponding historical full-logit vectors. Both kits preserve new executable identities separately from historical binaries.

\texttt{anc/source\_manifest.json} pins each campaign. Original RTX evidence is sealed at \texttt{f997262d}, the B570 support audit at \texttt{9fafc4ba}, RTX service at \texttt{9868acfb}, and B570 service/policy at \texttt{51febadd}/\texttt{e44c4df0}. Later transfer and native-delivery records retain their own execution freezes and result commits. Complete runtime and tensor archives are separately held, with retrieval paths and hashes in the companion records. Small native fixtures and formal RTX records are versioned; bulk logits, interrupted attempts, numerical libraries and model weights remain external dependencies. Fresh-directory checks reproduce execution on the originating hosts, rather than on independently provisioned machines. The manuscript package makes reported-data reconstruction independent of the bulk archives.

The later studies add recorded native execution on RTX and B570; manuscript reconstruction uses their saved measurements and does not rerun those experiments. \texttt{anc/historical\_disposition.csv} and \texttt{anc/editorial\_archive/} retain the 28 legacy groups and later failures. The archived \texttt{dae5aea9} AV model remains a same-policy parity control, with no hardware-performance claim. Generated TeX resides in \texttt{tables/}, outside \texttt{anc/}, so article compilation does not depend on ancillary-data handling. The README gives the check/build commands and separates CPU validation from native runtime requirements.
