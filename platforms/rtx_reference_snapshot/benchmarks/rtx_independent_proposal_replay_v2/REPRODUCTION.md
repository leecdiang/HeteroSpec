# Reproduction and evidence levels

This is new RTX H2 V2 work; older H1, latency, direct-ID and B570 studies are not altered or counted as new observations. USER_SPECIFICATION.md defines the gates. Read CLOSEOUT before attempting inference: stop classifications are real outcomes and unreached phases must not be reconstructed.

Hardware execution requires Windows x64 RTX5070TiLaptop CUDA0, the independently obtained pinned target/draft/data, original b10839 release DLL distribution, Zig C++ frontend compiler and Python3.11. Model/runtime/build bytes are excluded from published evidence. `prepare.py` reads exact prior evidence and extracts clean pinned headers; `audit.py` scans host scientific files and Git archive members without forward. `build.py` constructs separate P/R programs against clean headers and dynamically uses the original DLLs. `identity.py` rehashes external assets/runtime/frontend and observed driver files. Match effective config and recorded environment, rather than relying on version strings.

Engineering attempts are preserved separately. `qualification.py` performs 180 new reference executions then actual four-condition EOG and cap probes. `engineering_extra.py` examines exposed state/proposal paths, checks the original batch-debug observer against four new unobserved native runs, tests explicitly constructed acceptance branches, and mutates independent copies for verifier negative cases. Do not invoke reserved modes before their prerequisites.

`verify.py` uses only the Python standard library and never imports the runner. Example: `python -B scripts/platform/rtx_independent_proposal_replay_v2/verify.py EXTRACTED/reference-qualification --kind reference`. Archive reconstruction must run in a fresh directory, validate exact inventory and every byte, and prohibit bytecode cache with -B. The archive/anonymous package verifier entry points and exact paths are recorded at closeout. External omitted assets can be optionally rehashed on the original host but offline evidence verification must not claim to authenticate omitted model, runtime or driver bytes.

Absolute original-host paths are provenance only. Anonymous recomputation removes personal paths, usernames, Git author metadata and unnecessary exact timestamps, while preserving the original package. Anonymous data can recompute content equality and tape state, but cannot independently authenticate original external freeze times when those are removed.
