# Pinned llama.cpp common headers

These headers are copied from [ggml-org/llama.cpp](https://github.com/ggml-org/llama.cpp) commit `5266f24da75dc449bd56cbed7addb9c8e4a6a73e` solely to compile the M4 runtime-control harness against the corresponding installed `libllama-common` build 10809. The source project is MIT licensed. The build manifest records each header's SHA-256 digest. The `llama.h` and `ggml.h` headers are supplied by the pinned Homebrew installation and are not duplicated here.
