# Abstract resource and state contract

One workload/owner/epoch occupies the model at a time. Packed32-bit address tags encode role/query/key/channel and a reference to the global owner/epoch, not free cross-owner sharing. Every event must match that identity. The trace checker rejects another owner or epoch even at the same KV address.

The512B common state budget charges64B for global owner/epoch IDs, cycle/credit counters, per-cycle port/read/fill tracking and latches;20B per output context for accumulator, temporary product, packed cursor/busy/store flags, due-cycle and context/tag reference;12B per resident OR in-flight operand for payload, address/tag and packed remaining-uses/due-cycle state. Busy/operation/consumer identity is derived from the cursor/context, not an uncharged separate payload queue. Output STORE retains the accumulator until COMMIT; it has finite credits, ports and latency, no free extra output payload storage. These are abstract word-sized allocations, not the Python object RSS or synthesized RTL. Debug trace storage is host evidence, not on-chip storage. Unbounded Python integers for arithmetic are a host implementation of exact F32 operations, not an uncosted hardware datapath-width proposal.

MUL/ADD each occupy one issue slot and one context read bundle, complete after finite compute latency plus declared extra issue latency, and require one context write bundle. Future writes are reserved to obey shared writeback ports. Each MUL delivers two input words subject to broadcast/fanout limits. Identical addresses may multicast once per bank read; repeated consumers still spend delivery bandwidth. FILL shares bank ports with reads, fetch reserves future FILL ports, and all queues/backpressure are explicit. Two-operand reads are atomic:bank/fanout capacity<2 is rejected because multi-cycle operand staging is not implemented. No silent spill. Oldest-key-wave barrier and stable context order are one conservative legal policy, not a throughput optimum.

Output cycles include first fetch through final COMMIT. External supply_bytes counts F32 words at the abstract operand-store to local-buffer boundary, including native F16 V already converted exactly to F32. It is not native F16 DRAM bytes or actual cache traffic. partial_result_bytes counts per-operation F32 result writes, context_bundle_traffic_bytes charges20B read plus20B write per operation and STORE/COMMIT, output_bytes counts final F32 results. The model has no RTX clock, cache, DRAM, silicon area, physical bank wiring or kernel-launch calibration. Identical static mappings have identical zero mapping-change latency; the extra latency negative test adds explicit per-operation cost. No dynamically switched mapping with free state movement is claimed.
