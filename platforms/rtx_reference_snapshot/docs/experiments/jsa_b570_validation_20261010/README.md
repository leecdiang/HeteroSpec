本 PR 供 **Intel Arc B570 实验端读取并执行**。没有新增模型请求、实验结果或论文数字。主问题是：既有 B570 固定参考保持方案能否迁移到第二模型家族，以及相对 **B570 自己的普通目标参考 R** 是否有整请求收益。

**可以独立开始，不用等待 RTX 结束。** RTX 执行 PR #80 已在输出前选定 SmolLM2-1.7B-Instruct / 135M-Instruct Q8_0。本方案采用相同 GGUF 文件哈希，独立使用 B570/Vulkan、UB128 普通参考及既有 UB128→UB1/k2 候选。模型与预留输入元数据见 [COORDINATION_SNAPSHOT.json](COORDINATION_SNAPSHOT.json)；静态快照不证明 B570 运行资格，也不预言结果。

## 解释边界

旧 B570 研究已经结束：正式 E 为 119/120，候选/R 的任务中位数整请求比为 0.20129，候选约慢 4.97 倍。本轮不补跑缺失旧槽位，不重开该 Qwen 优化路线。第二家族是新研究问题。

B570 的主要合同仍是 **首个 runtime EOG（含）或 128 token**。完整 raw 数组、额外 suffix 及其成本另行保留、核对；端点一致不能写成完整 raw 数组无损。失败后不换模型、换候选或删除任务。

本轮补 B570 的第二家族与独立会话证据。同合同外部方法适配由 RTX 承担，B570 不另造 Vulkan 版 LLM-42。四轮可以同日完成，不构成跨日期稳健性复测。RTX PR #80 已采用作者允许的同日两会话修订；PR #79 原六日期设计不被写成已执行事实。
