# Executing-agent authority and bounded progress

Work from the actual head of this design PR in an independent result branch.
The author approves original-host phase-one execution, not cloud spending, model
replacement, global system installation or edits to the submitted manuscript.

## Continue autonomously through ordinary engineering

Recover the exact existing source/runtime receipts, inspect the actual host,
compile and bind the new candidate. Adapt paths, ABI, compiler flags, precise
source anchors, build manifests, telemetry parsing and storage layout as needed.
Use the final parent build, not a nearby provisional build. Inspect before patching.
Keep source diffs, original failed records and the new version; requalify when the
change may affect numerical execution. A helper assertion, missing local path,
staging drift or a failed build is NOT a scientific outcome and NOT a reason to
return merely a plan. Do not ask the author to approve each normal repair.

Recover small metadata/source inputs first; raw KV chunks only when qualification
needs them. Reuse the parent's canonical state reader, forced-R producer, exposure
index, signed capacity checks and owned-worker cleanup. Do not build another
universal transaction, provenance or supervisor system. Inputs and libraries are
not made public by this work; repository access remains unchanged.

## Independent workstreams prevent premature termination

RTX R0 -> R1 development/qualification -> R1 fixed structural matrix is the main
attribution path. R1 natural is conditional on an unanswered, non-alias natural
question, NOT on a desired speedup. Absence of a nontrivial interaction is a result,
not a request for more rounds. R2 is independent after its own numerical/resource
bridge: if R1 natural is skipped, select and freeze the same-design sixteen Qwen
roots specifically for R2. Do not wait for an R1 result that need not exist.

B570 B0 -> actual admission -> C1024/C4096 cells. A C4096 admission failure does
not erase C1024 or the clean source rebuild. Before closing C4096, inspect resource
accounting and recover the existing exact Smol assets; do not reduce safety floors.
A target-only fallback is permitted only as a separately declared deployment at
BOTH capacities, with references fixed before candidates; no mixed-residency
single-factor claim. Record the budget effect before launching that replacement.

Native alias review needs both source and real work observations. A matching
label, kernel count or grouping hash alone proves neither equivalence nor
redundancy. Source drift and alias-review uncertainty call for integration work,
not an unsupported PASS or premature SKIP.

## Scientific boundaries

Keep original R and its producer, output masks/reservation, termination and state
meaning. R1 C1024 changes candidates, not the oracle. B570 C4096 defines a new
capacity deployment before candidate outputs; do not silently rename it old R.
No model-name/input-position special cases; no output/acceptance/timing/crossing-
based natural selection. Known-token head slices are diagnostic, not natural data.

A numerical failure in development may be diagnosed and repaired generically,
then requalified under the same R. A failure after confirmation freeze closes that
version's confirmation: retain all slots. A repaired version needs its own recorded
freeze and genuinely new confirmation inputs; no targeted reruns of slow/failed
slots, no unplanned extension to reach significance. Partial costs can be reported
as partial, never as complete-panel estimates.

A hybrid that cannot be separated without a new arithmetic algorithm is a
structural coupling result. Complete the valid mechanism and service questions;
do not call an incomplete three-arm set a full factorial experiment. No new FA,
Q4, MMA, MoE, AUTO, paged/multisequence or speculative-profit sweep is approved.

## Resource and ending rules

Ceilings are RTX 3072 requests /4,000,000 decoded rows, B570 1024 /2,500,000,
including development, references, warmups, failed reservations and model work.
Reuse the original host's actual reserve floors and timeout/ownership protection.
Do not silently expand ceilings. Request count means logical model trajectories,
not processes: a burst worker consumes eighteen requests plus additional reference
work; forced-R suffix replay rows count as actual work, not one cheap label.
Before each phase calculate its remaining worst-case reservations, reuse same-
version evidence where valid, and preserve previously completed measurements.

If resources or an irreducible numerical boundary prevent one branch, close that
branch with its actual evidence and carry on with independent applicable branches.
Stop the whole experiment only at a shared safety/resource limit or after all
applicable branches are resolved. No indefinite rerun, neither all-or-nothing
stopping nor budget filling.

Deliver RESULT.md, SOURCE_AND_BUILD.json, numerical scope and first-difference
records, all performed slots, the complete estimator outputs, alias decisions,
actual work/cost counters and a clean build/reproduction entry. Create a result PR;
leave both design and result PRs unmerged. No arXiv edits and no cloud purchases.
