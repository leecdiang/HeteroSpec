# Third-party materials and provenance

- **Elsevier CAS template.** `authoring_kit/els-cas-templates.zip` is the unchanged official ZIP supplied through the authoring-kit source and independently downloaded from Elsevier's official CDN. SHA-256: `36d97da01c6bbd134f315bff6c3de553735e2550444a6ddd4f869ddc67a20757`. The official class/style headers and license notices are retained. The complete original distribution remains in that ZIP. `paper/cas-dc.cls`, `cas-common.sty` and `cas-model2-names.bst` match it byte for byte. The manuscript uses `unsrtnat` for first-citation numeric ordering.
- **Scientific inputs.** Included numeric inputs are unchanged copies of public project records. Each source URL, commit and hash is in the input/figure manifests. Model weights, private native records and external paper PDFs are not redistributed. Publication permissions and the final data deposit require author confirmation.
- **Fonts.** Scientific plots use URW Base35 P052; manuscript text uses the corresponding Palatino-family LaTeX setup with Latin Modern fallbacks. Fonts are embedded in the generated PDFs. Chinese notes use Noto Sans CJK where available. Font software is not bundled separately with this manuscript package.
- **Scientific workflows.** The project used fixed texts from K-Dense-AI scientific-agent-skills at `2d2065fb4520fa3f3f2bcf61cff26ec8b7eba4b5` and blader/humanizer at `b48c832f0f809c1b5658edbb838c2521b72f2413` as workflow guidance. Their software was not installed and their full texts are not redistributed here.
- **Repository name.** The legacy repository URL is retained as an evidence source. The manuscript does not adopt that name as its title. Liu et al.'s unrelated ACL 2026 paper with the same project name is cited as prior work using its verified publication metadata.
