# Mainline priority handoff and exact completed-job continuation

The user's current priority is PR205 actual EOG/remaining qualification, then
PR206 natural qualification. Formal panels are evaluated only after those gates.
The earlier continuation's unconditional `--run-panel` setting is superseded.

The scheduler waits for the current native worker's complete HOST, clock and
actual-module receipts. It only ends its own idle coordinator after confirming
that coordinator has no active children. No native worker, foreign process,
device or existing scientific artifact is interrupted or rewritten. The private
handoff observer receipt identifies its author separately from native evidence.

`continue_qualification.py` now requires the actual PR205 completion receipt and
an explicit completed-worker handoff receipt. It writes qualification-03 and a
separate source/status freeze. Original qualification-01, its900s timeout, and
all qualification-02 outputs remain. The first epoch's completed geometry is
still revalidated. Every reused native request must have the identical complete
job, actual executable/build/launch/capability/module bindings and COMPLETE HOST.
Consumed vectors and active state/frontier bytes are compared again by the same
reader. Completed native jobs are not rerun merely to change scheduling order.
Unstarted D4/reference work runs normally and remains charged to the same ledger.

The independent14B reference, numerical binaries, models, comparison rules,
grouping, original development inputs and prospective formal jobs are unchanged.
The fixed EOG diagnostic remains distinct from original CAP128 roots. No failed
partial native output becomes qualification evidence.

This entrypoint accepts no `--run-panel` flag and completes as
QUALIFIED_FORMAL_NOT_RUN only after all six controls, state/transaction, actual
projection/physical and native negative gates. The separate formal runner binds
qualification-03 and is callable only after a later panel-admission assessment.
M2, C4096 and32B GPU POC are not launched by this continuation. The32B download
retains its verified ranges and yields to this primary sequence.
