\subsection{Session sensitivity}
Table~\ref{tab:sessions} reports the two session estimates separately. Each is the geometric mean of the 12 task ratios, using four-repeat arm medians within that session. \subsection{A fair comparison is not a component profile}
PQ constructs separate attention subgraphs and concatenates their results; QB batches one-column attention instances; GS physically serializes active target rows across the network. The speculative arms retain the same draft protocol and reconciliation obligations. All three repairs satisfy the full output requirement in this panel, making their total request costs comparable. The table does not measure the isolated cost of attention or quantify how much of the advantage comes from graph construction, projection, FFN or synchronization.

For a ratio $r=T_a/T_b$, the corresponding denominator latency reduction relative to the numerator is $1-1/r$, not $r-1$. For example, a 2.144 ratio is not a 114.4\% reduction in latency. The main paper intentionally reports time ratios to avoid that ambiguity. The point estimates also have no fabricated error bars: the present reconstruction did not derive new date-level uncertainty from unavailable independent-day measurements.

\subsection{Implementation corrections and the final evidence scope}
Four PQ engineering warm requests on SmolLM2/Llama failed and remained charged. A resource correction increased host graph metadata capacity by a factor bounded by the predeclared maximum query count. Numerical backend libraries and operators were unchanged; the model, precision, mask, draft width and panel were unchanged. Previously started Qwen rows were retained, and affected unstarted arms were requalified. This is a disclosed amendment rather than a claim that no implementation issue occurred.

A QB eligibility check was corrected to accept the actually compiled final tensor alias when its geometry and existing full-output checks established the intended layout. The correction did not rerun GPU science or consult timings to select a faster condition. A final archive repair restored missing inherited package inclusion and corrected auditor metadata after the formal requests had completed. Original failed packaging logs and frozen files remain in the source archive. These corrections should be included in artifact review because a perfect-looking end table alone does not establish protocol compliance.

The original host reports independent standard-library recomputation, 14 synthetic rejection tests, and local/authenticated remote restoration. The finalization check independently recomputed all 21 aggregate and 42 session ratios from the pinned report's task/session median times and checked denominators, qualifications and table rounding; it did \emph{not} rerun the full native/raw scientific archive. That division of responsibility is explicit in the reconstruction QA record.
