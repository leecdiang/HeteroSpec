Speculative decoding changes the target's execution geometry, which can alter a quantized runtime's greedy output even when the acceptance protocol is correct. We introduce phase-scoped query-batch attention (QB), a graph transformation that places query columns on a batch axis while retaining batched projections and feed-forward computation. Query and mask views preserve native indexing semantics; role/phase guards and a layout-sensitive graph cache apply the transformation during target prefill and continuation. On 24 captured CUDA attention contexts, QB matches explicit per-query attention (PQ) bitwise at QK, softmax and AV. A separate three-family CUDA confirmation preserves complete registered outputs, and all seven arms qualify in a 2,016-request implementation study with an EOG-or-128-token endpoint. Speculative request-time ratios are 1.022--1.068 for PQ/QB and 1.463--2.176 for global serialization/QB; ratios above one favor QB. Adding a draft to the repaired path benefits Qwen3 and Llama but slows SmolLM2. Complementary Vulkan interventions show that prefill partitioning can change projection outputs and that retained KV differences can select later trajectories under a validated common receiver. These results identify a design choice for the evaluated quantized stack: constrain attention geometry while retaining other batching, and assess repair cost separately from draft benefit.
