# Build and reconstruction

All commands below are CPU-only. Run them from this package's root. They do not load models or execute native/GPU benchmarks.

## 1. Recompute the public timing panels

```sh
python paper/scripts/recompute.py --out paper/build/statistics_run
```

Use a new output directory on each run. The scripts refuse to overwrite result files. They validate complete root/session/arm grids and preserve original estimands, root ordering, bootstrap seeds, confidence families and S3 coding/mathematics strata. Results compare with fixed source analyses at an absolute/relative arithmetic tolerance of `2e-12`; this is not a relaxed inference-equivalence criterion.

The three underlying recomputation scripts are copied without modification from the fixed public closeout. Their hashes and source URLs are in `paper/generated/recompute_sources.json`. The legacy figures additionally reconstruct public paired ratios or root aggregates as specified in their manifests. These representations do not provide all original native tensor records.

## 2. Regenerate figures and editable tables

Dependencies used for this draft: Python 3, NumPy, pandas, Matplotlib, fontTools, Inkscape and URW Base35/P052 fonts. No optional scientific-skill software was installed.

```sh
python paper/scripts/build_figures.py
python paper/scripts/build_tables.py
```

The plotting script verifies source hashes, recomputes displayed point estimates, checks that observations remain within plotted limits, and writes vector PDF, editable SVG and preview PNG. PDF exports use Inkscape from SVG; its fonts are embedded. Numerical assertions and plot metrics are written to `paper/generated/`. Confidence intervals come from the frozen reconstructed analyses with their stated statistical units.

The table script generates six macros from unchanged numeric inputs. The all-control application and natural-episode tables are generated by the figure script. Edit the code and rebuild rather than editing plotted points or generated numeric tables.

## 3. Compile the documents

A complete TeX Live installation with pdfLaTeX, BibTeX, natbib, mathpazo, lmodern, microtype, enumitem, xurl, placeins and the standard table packages is sufficient. `pdftotext`, `pdfinfo`, `pdffonts` and PyMuPDF support verification. The official CAS class and common style are included unchanged.

```sh
python paper/scripts/build.py --target all
```

The script builds the manuscript, supplement and highlights with repeated LaTeX passes and BibTeX, rejects unresolved references/citations, and copies final PDFs to `paper/`. An optional `--figures` regenerates plots first. Use `build_tables.py` after changing table inputs.

In the preparation environment, TeX source files were present but filename databases, formats and font maps were missing. The script's fallback creates a local format and font-map cache under `paper/build/tex_cache`; it does not change system files or install software. Normal installations use their existing TeX setup. Missing packages still require an appropriate TeX installation.

`main.tex` contains the abstract inline because the CAS verbatim abstract capture does not safely expand an `input` command inside the environment. `abstract.tex` is the matching standalone editable abstract copy; keep it synchronized if editing. The checks compare these texts. `unsrtnat` supplies numeric references in first-citation order; the included official CAS author-order `.bst` is retained for provenance but not selected.

The author-review footer and omission of an empty ORCID field are configured in `preamble.tex`, leaving the official class/style bytes intact. The CAS keyword overlay emits a known zero-width-box overfull warning at `maketitle`; the rendered page is checked for visible overflow. It is not a dropped caption or unresolved reference.

## 4. Flat submission sources

Elsevier's verified LaTeX guidance says Editorial Manager cannot process source subfolders. The package therefore includes a separately prepared flat archive in addition to the maintainable working tree.

```sh
python paper/scripts/flatten_sources.py --out submission_sources
```

The script copies dependencies to one level, rewrites input/figure paths, includes the generated bibliographies and all vector figure PDFs, and creates a ZIP. The flat manuscript and supplement were also compiled and compared with the working-tree output by page count and extracted text. This preparation is not a journal submission. Authors should inspect the PDF produced by the actual submission system before approving it.

## 5. Chinese author notes

`author_notes/build_author_notes.py` produces the PDF from the Markdown notes, using ReportLab, fontTools, a Noto Sans CJK font and PyMuPDF for inspection. The first explicit page break preserves the one-page decision summary. The notes are internal author-facing material, not part of the journal manuscript.

## 6. What is and is not reproducible here

Public timing statistics, numeric projections, plots, editable tables and document builds are reconstructible from the supplied files. Sources for implementation and original experiments are linked by fixed revision. Native inference qualification was not rerun. Model weights, confidential company records and unavailable pruned intermediates are not bundled. A final archival data deposit and any legally authorized access process remain author decisions.

The delivery archive omits local TeX caches, raw build logs, private filesystem locations, credentials, downloaded third-party research PDFs and the older source repository checkout. The public scientific input files retain their original bytes.
