## 本次要研究的增量

候选是一个小型 **reference-constrained query-context packing** 单元：保持每个 query 的已声明数值分块、舍入点和状态输入，改变独立上下文的物理资源绑定与 K/V 供给。首版优先检验 AV 型加权归约原语；softmax 是固定输入边界，不免费改成 online softmax，不声称已经完成整层 attention 或完整模型的新实现。

目标是检验同资源强软件/固定调度基线之后是否还有具体余量，不是设计“提高模型准确率的 Tensor Core”。有序归约、动态 tile、KV 共享本身不作为独创。候选与强基线等效、无收益或被模型误差覆盖，都是有效结论。
