# Method and template sources

The verification reports preserve the exact primary URLs, versions and hashes
used for this rewrite. Downloaded template and third-party skill working copies
were read during preparation; they are not redistributed in this author package.
References to saved working-copy paths in those reports describe that preparation.
The manuscript's actual IEEEtran class and bibliography style are included at the
package root. `SCIENTIFIC_SKILLS_SOURCES.json` records the eight pinned scientific
skill identities; `../review/SKILLS_APPLIED.md` records their use in the paper.
