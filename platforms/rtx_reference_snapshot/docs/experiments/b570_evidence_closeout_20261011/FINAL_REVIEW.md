## 去掉会妨碍有效证据的限制

1. 正式全部 arms 使用 counts：保留原生输出和轻量整数工作量汇总；关闭逐阶段 elapsed hooks、heavy capture/状态 readback、新增同步和实验 ETW。请求起止计时与实际执行所需的检查照常计费。不能把复杂 profiler 的费用当部署算法税，也不宣称 counts 开销为零。
2. 曝光工程用 baseline/counts/lite/heavy 四模式。baseline→counts 测新增计数扰动，counts→lite 测时间戳扰动；heavy 只取形状/周期与驻留证据。每个配对差值、arm、长度和执行顺序全部报告，不能减去估计开销修饰主比值。接近盈亏边界且与观测扰动同量级的收益要标为测量敏感，不能强判部署优势。
3. B570 的物理驻留 UNKNOWN 限制 fully-resident 主张，不再阻止输出与实际请求费用研究。继续前仍须实际满足固定 512MiB signed headroom、全 GPU 放置日志及无已知分配失败/offload 等运行门槛。缺 ETW 权限/工具或分配归因不全只能记 UNKNOWN；真正的资源失败仍停止。新研究并列报告 request_qualified_ratio 与严格 resident qualified_ratio，后者没有对应正式 worker 全程证据就必须为 null。工程 trace 不外推到关闭 ETW 的正式请求。
4. 核心工程与 profiling 分账：RTX 每家族核心360 + profiling128 =488，总1464；B570 核心256（含最多6个 load probes）+ profiling128 =384。profiling 包含96个测量请求槽和32个加载/预热/失败余量；全部操作占其128，不能挤占核心额度；不能在额度之间借用。无须为凑齐模型耗尽额度，缺项原样交付。正式仍 RTX3600+150 warm、B5701200+50 warm；owned GPU-process16/8小时、外层7天不变。
