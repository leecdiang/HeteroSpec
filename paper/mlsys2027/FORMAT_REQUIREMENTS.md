# MLSys 2027 submission-format requirements

Checked against the official **MLSys 2027 Call for Research Papers** on 2026-09-18.

Official CFP:
- https://mlsys.org/Conferences/2027/CallForResearchPapers
- Submission site: https://openreview.net/group?id=MLSys.org/2027/Conference
- Official style package linked by the CFP: `mlsys2025style.zip` (MLSys 2027 explicitly reuses the 2025 submission format)

## Hard submission constraints

- Track: **Research Track**.
- Review: **double-blind**.
- Research-track authors must make a good-faith effort to anonymize the paper and must avoid explicit or implicit identification through self-reference, acknowledgments, or affiliations.
- arXiv/public technical reports are allowed, but the submitted paper itself remains double-blind.
- Main paper: **2-column format**.
- Main paper length: **up to 10 pages, excluding references**.
- References: outside the 10-page main-paper limit.
- **Every reference must explicitly list all authors**; do not use shortened author lists that violate this requirement.
- Appendices: unlimited in principle, but **must be uploaded separately from the main paper** and reviewers are not required to read them.
- Appendix deadline: same as the main-paper deadline.
- Use the official MLSys LaTeX style files; do not approximate the layout manually.
- Paper submission deadline: **2026-10-30 20:00 UTC**.
- Submission opens: **2026-10-10 20:00 UTC**.
- Reviews available: **2027-01-18**.
- Author response due: **2027-01-21**.
- Notification: **2027-02-28**.

## Policy constraints relevant to this repository

### Anonymization

For the research track:
- remove author names and affiliations;
- do not include acknowledgments that identify the authors;
- avoid phrasing such as "our public repository" if it trivially identifies the authors;
- repository/artifact links in the review version must be anonymized if used;
- self-citations should be written in the ordinary third person when possible rather than with identifying phrasing.

The repository may remain private during review. Public release and artifact packaging should be treated as a separate release task.

### Dual submission

The work must not be simultaneously under review at another archival conference and must not have already been published as a conference paper with substantially overlapping technical content. Non-archival workshops and public technical reports are exceptions described by the CFP.

### Artifact evaluation

Artifact Evaluation is voluntary for accepted papers and does not affect the paper decision. The existing repository provenance/manifests are useful preparation but are not themselves a substitute for the later AE packaging process.

### LLM-assisted writing

The CFP explicitly allows authors to consult LLMs while writing, but prohibits papers whose content is generated by LLMs alone except for illustrative/experimental use. Therefore:
- all technical claims must be checked by authors against repository evidence;
- generated prose is a drafting aid, not an authority;
- figures/tables/numbers must trace to tracked evidence;
- final wording and scientific judgment require author review.

## Deliberate non-assumptions

This file does **not** invent details not stated in the current CFP/style package, such as font sizes, margin dimensions, bibliography package options, or final-camera-ready page policies. Those must be taken from the official style files once imported.

Do not create a hand-written imitation of the MLSys layout.

## Submission QA checklist

Before submission:
- [ ] Official style package is present and unmodified except for normal paper content.
- [ ] PDF is 2-column and main body <= 10 pages.
- [ ] References begin after the 10-page main body.
- [ ] Appendix is not embedded in the main-paper PDF.
- [ ] All bibliography entries list all authors.
- [ ] Author names, affiliations, acknowledgments, metadata, PDF properties, figures, and repository links are anonymized appropriately.
- [ ] No accidental local file paths, usernames, hostnames, GitHub account names, or institution names remain in the review PDF.
- [ ] No result is sourced only from an unmerged/unstable experiment branch without being marked provisional during drafting.
- [ ] Every quantitative claim has a repository evidence pointer in the internal evidence ledger.
