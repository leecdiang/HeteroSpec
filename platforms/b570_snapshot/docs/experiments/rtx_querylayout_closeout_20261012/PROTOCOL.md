## 1. Scientific questions (pre-registered)
**Q-MECH**: For the *same actual Q/K/V values*, mask, logical positions and retained KV, where do original multi-query (MQ), per-query attention (PQ) and query-batch attention (QB) first disagree (QK, softmax, AV)? Does QB match PQ's numerical outputs / selected reference decision at those boundaries? Tensor shape alone does not establish identical GPU reduction order or bitwise arithmetic.

**Q-COST**: Among independently qualified full-output-preserving implementations at identical model/backend/prompt/timer contracts, is QB cheaper than PQ and globally serialized target execution? Test both draft-free and k3-speculative paths. **M3/C3** remains a separate *incremental speculation* comparison and must not be mislabelled as the cost of consistency repair.

Hypotheses may fail. The mechanism claim must be narrowed if QB does not numerically resemble PQ at the sampled operator; the efficiency claim must be null if comparators fail output qualification or have non-equivalent paid scope.

## 3. P1 — Fixed-input operator-level causal probe
Use **exposed diagnostic inputs only**. From archived PR91, deterministically select per family two M0-divergent tasks and two R/M0-agreeing controls (prefer one per domain where available; otherwise document the selection constraint), sorted by frozen task IDs, plus the existing Qwen MBPP/229 width-boundary case if the original exact model/geometry can be reproduced without changing scope. Historical HE/15 (repair), HE/25 (regression) may be used as distinct labelled historical probes. Do not call any of these new or blind holdout tasks. Freeze selection prior to mechanism runs.

For each admitted case, capture from native execution at the first relevant multiquery verification boundary (or closest demonstrable prefill/continuation boundary) the **actual raw Q, K, V, attention mask, strides, shape, position, cache pointers/index ownership, q occupancy, numerical dtype, heads/GQA mapping, logical committed prefix, pending token**. Include early and first-divergent boundaries where practical, with at most **24 distinct snapshot contexts** total. Store exact bytes and hashes; confirm bitwise-identical fixed inputs for all replay arms, including K/V layout and mask semantics. If consistent replay buffers cannot be obtained, mark `INPUT_NOT_IDENTICAL` and do not draw arithmetic causal conclusions.

Replay the same snapshots under:
- **MQ**: ordinary batched multi-query attention implementation.
- **PQ**: explicit per-query attention graph and deterministic recombination.
- **QB**: actual implemented query-as-batch view and shared K/V broadcast.

Use ≥3 repeated runs per snapshot/arm if feasible to detect within-arm variability. Instrument independently of paid timing. Compare QK outputs, post-mask scores, softmax probabilities, AV/attention output, optional output projection and logits if full-path state is available; report shape/strides/byte hashes, first divergent operator, max absolute/relative error, bitwise equality count, ULP distance when representable, argmax + top2 margin at actual decision. When a tensor cannot be matched at a comparable semantic point mark NOT_COMPARABLE; do not synthesize intermediate logits from mismatched states.

**Mandatory actual kernel evidence:** backend operation dispatch and kernel symbol/algorithm, launch/grid/block (or relevant cuBLAS algorithm descriptors), dtype/accumulation, q width, and input pointer/stride identity. Nsight/CUPTI if available; otherwise record runtime dispatch traces and mark kernel-level scheduling UNKNOWN. A ggml node name or graphical shape is not proof of an identical CUDA reduction schedule. Trace capture/sync only in diagnostic runs.

**Adversarial controls:** bitwise duplicate-input replay; identical-arm replay; changed mask/position rejection; failed topology cache-key reuse rejection; capture-on/off semantic check; own-path native replay control. If the divergence is upstream of Q/K/V creation, or fixed-input operator arithmetic is equal, report that honestly: evidence then supports a different state-formation mechanism, not QB's reduction equivalence.

## 4. P2 — Full native output + comparable paid repair cost
Seven predeclared conditions, separate resident processes:
- `R`: ordinary UB1 greedy fixed reference.
- `M_QB`, `C_QB`: mask3 QB target-only / k3 speculation (the current repaired path).
- `M_PQ`, `C_PQ`: mask3 per-query-subgraph target-only / k3 speculation.
- `M_GS`, `C_GS`: globally serialized target-only / k3 speculation.

All **PQ/QB/GS** conditions must use same target, draft (for C), tokenizer, precision, prompt, context, cache reset, stop, phase eligibility and output contract. PQ/GS differences must be the declared repair implementation, not changed draft proposal, arbitrary fallback, smaller model, extra reference-answer assistance or separately optimized batch. For historical-global-mode incompatibility, record NOT_IMPLEMENTABLE and why; never replace it with a hidden slower or differently scoped condition.

Preselect **12 exposed PR91 tasks (6 MBPP+6 GSM8K)** by a deterministic, pre-output task-ID rule frozen in F0B; do not select by speed, divergence, length, or favorable model results. No claim of fresh-input transfer or cross-date inference. Use two independent resident sessions per model, four balanced rounds per task/condition; **7×12×2×4=672 formal requests per family** only if budget admission explicitly permits. This is **up to 2,016 formal requests total** across three existing families, not a mandatory rerun of #91. If time/memory cannot admit all three, predeclare a smaller scientifically defensible subset *before first F0B*, preferably Qwen+Llama with Smol as separate negative test; never choose after seeing repair costs. One excluded warmup per condition/session (=14 per family), allowing 28 per family as safety ceiling. No retry/overwrite of started formal slots.

**Priority when constrained**: produce operator-mechanism evidence for all admitted families first; execute P2 on Qwen (primary) and one transfer/negative family according to a pre-declared resource gate. A globally serialized control that is prohibitively slow is a measured/declared stop, not replaced by a smaller-token response. No cost claim if missing/imbalanced/nonqualified paired slots.

Paired native full token-ID sequence, length, EOG, terminal, stop reason versus **newly registered stable R** with identical inputs and cap128 is a prerequisite *for every comparator used as equivalent*. Per-task per-session median of four absolute paid HTTP costs, log ratios averaged across tasks and then sessions; report individual sessions, domains, all task regressions, missing slots. Ratios >1 favor **QB** in `C_PQ/C_QB`, `M_PQ/M_QB`, `C_GS/C_QB`, `M_GS/M_QB`. Also `M_QB/C_QB`, `R/M_QB`, `R/C_QB` separately; none proves a component-time attribution.

One declared **complete nonstreaming resident request timer**, no added sync/readbacks/phase timers in paid mode; separate observational diagnostic modes for kernel tracing and source-counter audit. Report observer perturbation without subtracting estimated overhead. If actual kernel P1 data requires expensive instrumentation, never mix into P2 paid traces. Fixed no-prompt-cache reuse or record and reject if violated. Two adjacent sessions are **not independent dates**. No fitted break-even model or energy/throughput claims.
