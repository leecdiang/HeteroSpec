Figure S1. Qualified request costs for the same 12 exposed tasks in each family. Green circles compare local repairs with a draft ($C_{\PQ}/C_{\QB}$); ochre triangles compare adding a draft to repaired target-only execution ($M_{\QB}/C_{\QB}$). Each point is the geometric mean of two session ratios, each formed from four-repeat arm medians. The shared horizontal axis is logarithmic; values above one favor QB for circles and adding a draft for triangles. Vertical offsets separate the two comparisons on each row. The dagger marks Llama GSM8K141's repair ratio of 0.999919, a small regression that would round to 1.000 at three decimals. These are 36 family--task pairs, not 36 independent tasks.

Figure S2. Task-level PQ/QB request ratios in two adjacent sessions. Columns identify families; the upper and lower rows show target-only and speculative execution. An open circle and a filled square give the first and second session ratios of four-repeat arm medians; each gray segment connects the same task. Markers are vertically offset only to prevent overlap. All six panels use the same linear axis and the same task order; values above one favor QB. The 72 paired segments are descriptive session comparisons, not independent-day replicates, confidence intervals or a measured temporal trend.
