五、Phase D：分析和解释

每个四格比较必须对应同一 task、recipient、初始 logits、token prefix、逻辑位置、采样规则和观察条件。
不要求 KV 相同：KV 是受操纵对象；但不同 token 前缀的 logits 不可直接用于本分析。
禁止把不同 arm 各自首次分歧处的 logits 不加对齐地放进同一个四格。
禁止在分歧后继续把自然生成的不同文本当作“同输入”。

令 d_S=z_S(u)-z_S(r)。
L0 主效应和残差：
  delta_K=d_K-d_EMPTY
  delta_V=d_V-d_EMPTY
  I_KV=d_KV-d_K-d_V+d_EMPTY
POSITION 残差：
  I_pos=d_ALL-d_prefix-d_tail+d_EMPTY

同时保存 full logits 与 vector-level residual，而不仅一个 token pair。
CPU 运算用明确的 FP64 分析路径；报告每个独立重复的值、差异及实际数值精度。
不以一个随意 epsilon 把小残差宣布为零，不从两次确定性重复构造人口置信区间。
不预设残差一定很大；即使端点非单调而连续分数接近可加，仍然是需要报告的结果。
残差是这个受控四格下的净分数非加性，不是自然间接效应的完整估计，也不识别唯一 kernel。

辅助诊断：
EMPTY 的 top1 margin m 与 epsilon=||z_S-z_EMPTY||_infinity。
m>2*epsilon 是该已观测共同前缀位置 top1 保持的充分条件；反向不成立。
它不是新理论贡献、不是全序列保证、不是允许省略未来验证的运行时算法。
完整词表有第三候选时，一并检查真实 argmax/rank；不能只看 u/r 就解释第三轨迹。
无端点变化仍需报告数值变化；cap128 下无变化不能外推到更长生成。
