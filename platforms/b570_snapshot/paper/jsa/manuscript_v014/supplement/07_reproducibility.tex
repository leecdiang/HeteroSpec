\section{Arithmetic Reproduction, Provenance, and Remaining Access Limits}
\label{supp:reproducibility}
The author S2 package provides editable LaTeX tables/equations, separate vector PDF/SVG figures, bibliography, Highlights, CPU reconstruction and build code, selected authenticated report/implementation records, claim--evidence mapping and the complete experiment-destination ledger. It includes the retained Elsevier class and numeric bibliography style. The two document entry points are \texttt{main.tex} and \texttt{supplement.tex}. Compile either directly in Overleaf; the documented local build regenerates tables and figures from the frozen exports before compilation.

The inherited 26-file evidence binding and 16 historical source copies remain byte-for-byte unchanged. Reproduction checks reconstruct the RTX 384-row matrix, qualification flags and response-ID digest bindings, medians, all 12 comparisons, descriptive intervals, task regressions, round reversal and the ratio identities. They independently reconstruct B570's 119 formal rows, 15 versus 14 complete task pairs, all three cost timers and paid suffix counts. The phase task booleans, natural-state matrices, fixed-UB task-ratio aggregation and M4 medians/oracle are also checked. Counts inferred from compact exports are distinct from a renewed audit of every original raw payload.

The original runtime reports contain stronger original-host audits, retained external-asset hashes and large content-addressed archives. This reconstruction reads those reports and source, authenticates the copied Git blobs, and recomputes included exports. It does not reconstruct every private archive, locally rehash omitted model/driver binaries, verify independent absolute execution time or run new GPU experiments. Numerical reproduction of a summary or task-ratio export must not be called a full raw-data audit. Missing B570 payloads and unknown suffix comparisons remain unknown.

Clean source-package extraction and rebuild check document text, citations, embedded fonts and build diagnostics. Final PDFs are rendered and inspected page by page, including figure labels and table continuations. Numerical and build QA records state actual executed checks; visual QA records identify the inspected final pages. These are author-side validation activities, not external peer review or commercial plagiarism checking. The draft PR is a review entry point rather than journal submission.

HumanEval, MBPP and Spec-Bench source descriptions are cited in the main manuscript~\cite{humaneval,mbpp,specbench}; software is cited directly~\cite{llamacpp,qwen3}. Web/preprint versions and access dates are recorded in the bibliography and reference audit. Authors must finalize authorship, affiliations, CRediT, funding, competing interests, permissions, permanent data/software access and the AI-assistance statement before submission. A second model family, external method implementation comparisons, stochastic sampling and concurrent throughput are outside the completed evidence scope; no future outcomes are supplied here.
