# Declared architecture AV reference

This is DECLARED_ARCHITECTURE_REFERENCE, not reconstruction of proprietary RTX arithmetic. P is a fixed F32 softmax-boundary input. V is finite F16 converted exactly to F32 or explicitly synthetic F32. For each (query, channel), start at +0, iterate keys in increasing order, round each multiplication to F32 nearest-even, then round each addition to F32 nearest-even. No FMA, reassociation, masked-zero skipping or online softmax is permitted. Independent contexts may interleave.

Finite normal/subnormal values and signed zero are supported with gradual underflow. Multiplication uses sign XOR for zero. Addition of two -0 is -0; other exact cancellation is +0. Non-finite operands and operations overflowing the largest finite F32 are rejected; they are not silently replaced or dropped. The formal input panel is checked before registration. The independent checker uses exact rational arithmetic with binary search between representable F32 neighbors, distinct from the integer exponent/rounding implementation used by the scheduler.

Native sources are completed, authenticated PR104 E1 operands, after final PR104 seal f997262d6b0accb126a1217c9356745cc8bbf708. Select at most24 (family,phase,q) groups, first own-path/lifetime/repeat-qualified context in fixed layer0/middle/last priority. Selection does not consult PQ/QB equality or timing. Retain original hashes, actual geometry, native caller trace, MQ own-path/repeat/readback evidence. Crop head0/KVhead0, first two value channels, first min(64,key_extent) keys, all physical queries using original strides. Exact F16→F32 conversion preserves V values. P is not renormalized after cropping. These are NATIVE_OPERAND_SUBVIEW_PR104, not full-operator replay or recovery of deployed RTX arithmetic. Missing groups remain NOT_AVAILABLE. Synthetic sources use separately labeled seed20261015. Nonfinite/overflow inputs are rejected by the predeclared finite contract with all failures retained.
