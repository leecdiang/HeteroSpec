# Limits of this RTX epoch

- Finite, strict native Windows qualification supports the tested full-vector, active-KV/frontier and lifecycle cases. It does not prove universal losslessness or correctness of benchmark answers.
- The 16 formal roots were selected by ID/domain/length and were outcome-unexposed in the audited project history. This does not mean model-training-unseen. The audit excluded the full historical PR195 reserved pool conservatively and inspected all39 pinned PR62 exposure JSON files; an initial empty sparse-path reader was rejected and preserved.
- All clean timing uses one qualified V2 frontend/backend epoch, cap96, prompt≤192, one Laptop GPU and the existing Balanced power scheme on AC. Fixed settings do not establish constant frequency. Eight Williams blocks are order blocks, not eight devices or eight independent days.
- Qualification fixtures and concrete job manifests were frozen incrementally by stage. The design preceded execution, but not every future qualification-fixture byte was published before the first qualification output. The complete C/D source/input/order/job/row/statistics manifests were published and fully read back before all clean C/D output.
- The full PR210 source/cost protocol was read after initial geometry qualification and before clean timing. This deviation from the design's pre-implementation reading order is disclosed in SOURCE_REVIEW_ADDENDUM.json. No A5000 work/budget or optimization was imported.
- The first live worker completed its original18 native requests, then a Python mask reader misinterpreted caller-global indices. The immutable failed reader, exact worker files/hashes and independent offline verification remain. Only the reader changed; the native epoch/input/order/data did not. The original first worker was reused without GPU rerun. The resulting unscheduled inter-worker gap remains in complete cost and block summaries.
- An offline recheck also encountered an existing immutable completion marker. The helper was made idempotent only for identical marker content; the failed version was preserved. No new native request or favorable replacement resulted.
- All1024 live measurements and128 live primers are retained. Diagnostic128 measurements and32 primers are separate. Qualification and model/reference generation never enter the clean estimands. Expected negative native attempts are charged without refund; missing actual work on abort is null, not zero.
- Optional profiling was not run. Synchronized host decode/phase clocks, graph counters and unassigned residuals do not isolate kernels, CUDA graphs, launch, logging or allocation costs. Device-wide2s resource samples are sampled extrema, not guaranteed peaks or per-process peaks. GPU power is not whole-system power.
- Load/setup/first-result/burst/worker/wrapper windows overlap. Initial engineering/source-inspection time is only partially metered; its total is null. The retained measured subsets cannot be presented as a complete engineering total.
- Paired-root bootstrap intervals condition on this finite cohort and implementation. They retain all arms and blocks, use16 clusters and Bonferroni within each predeclared four-comparison family. Interval overlap with no change is not evidence of equivalence. The secondary family is separately labelled and cannot be used to invent a selected-winner primary claim.
- Equal-work diagnostic cells use four fixed exposed development roots and describe physical-width operation costs under equal input/state/output contracts. They do not estimate a population effect or directly predict live k7/k3 behavior.
- New scalar R endpoints are correctness references, not a timed target-only M arm. Old target-only timing is not a contemporaneous control. No speculation-versus-M superiority is established.
- RTX/A5000 comparisons also differ in OS/CPU/driver/build/cohort/horizon. This study supplies an implementation-specific operating envelope; it cannot attribute between-platform differences directly to GPU architecture.
- Public packet/hash readback and exact offline statistical recomputation prove evidence consistency, not independent numerical qualification on another host. Complete selected raw binaries remain in the local CAS archive and restored directory; model weights are excluded. Parent numerical-source reconstruction remains the explicitly pinned PR195 dependency.

Preparation helper failures, including the host Python alias, initially absent Git identity and a connector's empty large-file text response, occurred without model execution. The supported Python path, explicit Git identity and full Git blob readback resolved them. They are distinct from the eight intentional native negative-contract cases and the post-native live reader failure.

Two offline closing helpers also failed without inference: localized `powercfg` output used a mismatched default character decoder, and a cost-annotation reread hit the immutable existing output-file guard. Their failed versions/receipts remain. Raw-byte GUID verification and a fresh `cost-rechecked` output directory resolved them; original derived costs and all native records remain. One idle `nvidia-smi` sample reported an implausible46260MHz graphics clock, retained and annotated rather than interpreted as operating frequency or used to remove timing data.

The first archive inventory also stopped before creating a ZIP because identical-content compiler operands at different original paths shared a SHA256/basename alias. The repaired inventory requires exact byte hash/size equality, retains all source-path aliases and rejects conflicting contents. Its failed version is retained; the destination was empty and no raw file changed.

No merge, Release, original-data deletion, historical-baseline or paper edit, 32B/B570 launch, new model/precision sweep or automatic optimization campaign is part of this epoch.
