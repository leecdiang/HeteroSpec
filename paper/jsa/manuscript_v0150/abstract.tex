Speculative decoding changes the target model's execution geometry as well as its invocation count. In a quantized runtime, this can change a registered greedy reference even when the decoding protocol is mathematically valid. We present a phase-scoped query-layout transformation that decouples attention query geometry from target-wide batching. It moves attention query columns into a batch axis, preserves shared key/value and mask semantics, and retains batched projection and feed-forward computation. Role/phase guards and a layout-sensitive graph-reuse check enforce the transformation during target prefill and continuation. Across 24 captured CUDA attention contexts, query-batch and per-query implementations produce bitwise-identical QK, softmax and AV outputs; ordinary multi-query execution differs. A separate three-family confirmation study preserves complete registered outputs, and a 2,016-request implementation comparison qualifies all seven reference, target-only and speculative arms. Query-batch achieves measured request-time ratios of 1.022--1.068 over per-query speculative attention and 1.463--2.176 over globally serialized speculative execution. Adding a draft on the repaired path remains beneficial for Qwen3 and Llama but not SmolLM2. A complementary Vulkan study localizes prefill-partition differences to first-layer projections and demonstrates conditional suffix sensitivity to retained KV under a validated boundary-state reconstruction. This is not a Vulkan port of the attention transformation. The results support an explicit, empirically qualified runtime design rather than an unrestricted determinism guarantee, and distinguish efficient reference repair from profitable speculation.
