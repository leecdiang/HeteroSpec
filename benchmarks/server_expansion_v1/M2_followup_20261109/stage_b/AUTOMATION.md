# Detached server continuation

The host-side coordinator, resource observer and closeout supervisor run in
separate sessions, with no controlling terminal, file-backed stdout/stderr and
no dependence on a client connection. The supervisor and record adapter use
closed stdin. A laptop or SSH disconnect does not stop these server processes.
This is not a promise of surviving a server reboot, power loss or host failure.

The bounded chain is independent R replay/extension and full-vector/state
qualification, then only eligible frozen Stage B timing, then local archive
generation and exact saved-statistic replay. Resource conflicts or failures
retain evidence and stop admission. No C/D/E, 32B, full performance panel or
unbounded native retry is started. New-worker and hard-closeout boundaries
remain those in ADMISSION_PUBLIC.json.

A narrowly scoped record adapter retains the parent's duplicate-key table
construction error, original qualification and immutable timing plan. It verifies
and reuses completed native slots; it launches only slots that were never
reserved. Numerical code, criteria and measurement order remain unchanged.
It refuses to continue if the parent stopped for any other reason.

The supervisor records private heartbeat and terminal receipts under the run
root. A successful terminal receipt distinguishes completed measurements from
stopped-but-archived evidence. Archive consistency never substitutes for native
qualification. No GitHub credentials are installed on the server: public upload
and anonymous public readback remain pending until an authorized client can
connect, even when local archive/replay has completed.

The original driver/source epochs, helper failures, startup/load/restore costs,
raw numerical captures and conservative reservations are retained. Source files
for the supervisor, adapter, terminal exporter and public replay accompany this
document. Do not modify a frozen driver merely to make it resume.
