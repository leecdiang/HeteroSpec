## 记录和复算

所有192个计划槽位均为各条件资格分母。只按完整 runtime-native IDs、length/terminal/stop reason 比较所有实际 paid R；原始 suffix、FAILED/STARTED/MISSING 全部保留，不截断取合格、不补跑正式槽位。无关 N/k1 条件缺失不会消除已经完整的 R/M3/C3_K3 比较。

每任务/条件/会话先取四轮绝对 HTTP 费用中位数，再平均24个任务的 log ratio，最后平均两会话。每域、每会话和回归任务均记录在 RESULTS.json。k1/k2 全部报告，没有改选主配置或将请求数当独立日期样本。

全量 offload、F16 KV、ctx1024、FA off、single seq、threads24；请求 logical batch2048 被未改动原生 runtime 限制为有效1024。targetUB1/4，draftUB1。三家族共用发布数值 DLL，完整 SHA256 绑定。Llama target/draft 使用目标模板同一套 IDs；conversion 只认证公开发布字节/revision，未认证官方原始 checkpoint 转换血缘。

工程阶段实际 proposal/accept/reject/bonus/correction、verify宽度、rollback、head shapes、scope/reset、graph reuse 与 capture-on/off 对照见 ENGINEERING_RESULTS.json。逐 phase GPU timer 不充分时明确留空；capture 同步开销不当作正式费用，也不声称唯一算子因果。

RAW_EVIDENCE.zip 为 CPU 复算包；完整私有源码/程序在单独 author archive，模型和数值 DLL 外置按 hash 绑定。独立本地恢复与实际认证远端读回的 CPU 复算凭证分别见 RESTORE_LOCAL.json、RESTORE_REMOTE.json。旧 PR #80/#82 结果不改写，未修改论文、release，也未合并 PR。
