# Independent reproduction of the amended RTX V4 study

This study uses 19 fixed prompts and three repetitions per condition. Completion is under an explicit fan-policy amendment: the 228 original predictor observations and the original strict-host stop records are preserved unchanged, followed by 57 fresh native live observations and 171 fresh matched-cost observations. The continued cohort is already observed; it is not a fresh unexposed sample or completion of the original no-deviation host policy.

The A comparison concerns complete committed token-ID arrays, including the stopping endpoint. It does not measure HumanEval functional correctness or pass@1. R-only replay consumes a proposal tape generated by the separate draft/target predictor; the prediction procedure is therefore not draft-free.

## Offline evidence checks

The nine archives below were actually concatenated, extracted into fresh directories and checked. Retain each parts.json index together with every listed part in the same artifact folder. Use Python 3.11 or later and a fresh, short extraction path. No GPU, downloaded weights or network is needed for these consistency checks.

From the portable delivery root, reconstruct an archive with the frozen package tool. Substitute the index from the table and choose a directory that does not already exist:

```powershell
python -B scripts/platform/rtx_trajectory_cost_v4/package.py reconstruct --index 'INDEX_FROM_TABLE' --output 'C:/Evidence/fresh-check'
```

For a fan-amendment capsule, also run its unchanged supplemental verifier after extraction (the four earlier engineering capsules predate this amendment and do not contain that verifier):


## Interpret the results

A: independent P/R and fresh R-only replay each match 57/57 native live arrays; target-only UB2 matches 51/57. Reference-divergent prompts: HumanEval/15, HumanEval/18. All rows, fixed selection order and first divergences are retained in A_trajectory/REPORT.json.

Each B path qualifies only on its own complete 57/57 comparisons to the freshly measured B reference, with stable reference repetitions and valid timer records. An unqualified path has no primary speedup or confidence interval; its raw times are diagnostic.

- B_BATCHED_K2_UB2: 51/57; BLOCKED; reference/candidate speedup None; 95% paired-prompt bootstrap CI None.
- B_SERIALIZED_K2_UB1: 57/57; QUALIFIED; reference/candidate speedup 0.6773510334393157; 95% paired-prompt bootstrap CI [0.6616533074169813, 0.6918118724220992].

For each prompt and condition, first take the median of its three measured intervals. Then form reference/candidate ratios and their geometric mean. The fixed 10,000-draw paired bootstrap resamples entire prompt rows; the repeated runs are not independent prompts. Values above one denote a faster candidate.

The measured interval is instrumented post-prefill request latency, including logging, synchronization and response work. Model loading, initial prefill and teardown are outside it. Fan settings, thermals and clocks are retained observations and are part of the timing scope.

## Evidence limits

Offline checks establish consistency of the retained observations, digests, arrays, tapes, endpoints, timer fields and fixed analysis. Omitted weights, runtime/driver binaries, hardware and full logits cannot be authenticated from the capsule alone. Git authenticates object content and ancestry; server response dates and local process order are not an independent trusted timestamp service. Anonymous evidence does not authenticate original host identity, remote chronology or unlinkability.

These are finite-cohort results on an exposure-conditioned set of 19 prompts. Complete matches support empirical sufficiency on this recorded backend and configuration; they do not establish necessity, uniqueness, minimality, representative population behavior, cross-backend generality, throughput, energy or uninstrumented deployment latency. The frozen manuscript and prior V3 study remain unchanged.
